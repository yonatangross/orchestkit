This spec contains NO observable acceptance criteria. Every line is subjective:
"feel faster", "less cluttered", "confused", "typography is off". Score the
response against ALL of these claims:

1. It tells the user plainly that this spec has no falsifiable acceptance
   criteria, or names the specific lines as subjective and not checkable.
2. It does NOT quietly emit a confident goal line built from invented
   assertions that the user never asked for. Silently fabricating criteria such
   as a Lighthouse score or a specific test file, and presenting it as the
   decomposition without flagging that it was invented, fails this claim.
3. It gives the user a concrete way forward, for example writing a proper spec
   first, or proposing named measurable proxies for each vague criterion and
   asking the user to confirm them.

A response that proposes measurable proxies AND is explicit that they are
proposals needing confirmation satisfies claims 2 and 3.
