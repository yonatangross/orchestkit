design-to-code ship: a quote in the PR title no longer breaks the command

Ship mode opened the PR with the title and body written between single quotes inside the shell line. A name from the export that holds a quote, a $( ) or a backtick ended the quote early, and the rest ran as shell.

What changed

  
In design-to-code/references/ship-mode.md, Phase 4 writes the PR body to .claude/design-handoffs/<bundle>.pr-body.md and builds the command with a small helper, pr_create_cmd, that applies shlex.quote to the title and the path. The old --body @- form is gone. A test extracts the helper from the doc, runs the command it builds against a stub gh with a hostile title, and checks the title arrives as one argument and nothing inside it runs.
