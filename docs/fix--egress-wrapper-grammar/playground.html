Exact option grammar for command wrappers in the egress check

Front wrappers ahead of an interpreter are peeled with a fixed option grammar per tool. An option that tool does not know makes the whole right-hand side an unknown program. Login modes that change home also make the working-directory set unknown, so relative program paths stay fail-closed.

How wrappers and login modes are handled

  1. Match each wrapper on its basename, then consume only options that tool documents.
  2. After options, the next token is the command (except timeout, which takes one duration first).
  3. Login modes clear the cwd candidate set; a relative program path is then denied.
  4. A user-switch tool with an inline command string is scanned like an executed body.
