Targeted pre-push, opt-in only

Lane pushes were each running the full local suite (92 unit + 22 security files) while seven worktrees shared one host. ORK_PRE_PUSH_MODE=targeted narrows three stages by diff; everything else is unchanged, and anything uncertain falls back to the full suite with one WARN. Pick a diff and see which stages run.

Fallbacks (one WARN, full suite)

An unknown ORK_PRE_PUSH_MODE value, a diff base git cannot read, or a missing selector library. Nothing is ever silently skipped.

Why CI is still the gate

Targeted only narrows the local signal. The deferred line names the required checks that still run on the PR before merge.
