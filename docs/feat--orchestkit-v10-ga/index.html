What changes

AreaChange
Release.release-please-config.json: release-as: 10.0.0, prerelease: false, the beta keys removed. release-please reads the config from main, so the open release PR regenerates as 10.0.0. A follow-up PR removes release-as after the tag. No tag is edited by hand.
Rebrandorchestkit.dev replaces the old host in docs, README, packages (default base URLs and homepages), server.json, CI messages and the Lab page heads. History stays as it was: CHANGELOG, dated playground folders, audits, ADRs and approved mockups. Links to the studio and to Yonatan stay.
AboutA Creator section names Yonatan Gross with his GitHub link. A Contributors section lists the GitHub contributors API snapshot, people first, bots apart and marked Bot.
NavDocs, Cookbook and Reference open submenus. About joins the bar. The logo goes to the home page. The nav keeps George (operator decision); the nav icon comes from one BRAND.mark slot. The new rose window icon ships as the product icon in its own PR.
