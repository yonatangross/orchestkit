secrets-veil 0.0.10: a vendor prefix inside a tool name is not a token

The veil matched vendor prefixes as bare strings. The 1Password service-account prefix (o p s _, spaced here) sits inside every hq-ops MCP tool name, so 0.0.9 masked those names from the prefix to the end of the word and the tools never resolved in a seat that loads the veil. The Stripe live prefix did the same to identifiers like a risk_live_status column. In 0.0.10 those two prefixes count only when they stand alone (no letter, digit, underscore or hyphen before them) and carry a real token body. Every token below is built in the page from split parts; none is real.
