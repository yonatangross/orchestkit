Playground links die on merge

Every merged PR's Open Playground link 404s, because the URL pins the branch name and GitHub deletes the branch when the PR lands.

What happens

PR open branch fix/yaml-prose-leftover exists blob/fix/yaml-prose-leftover/docs/.../phantom-symbols.html 200 OK PR merges GitHub auto-deletes the head branch blob/fix/yaml-prose-leftover/docs/.../phantom-symbols.html 404 GONE the FILE is fine, it is on main. the ref is what vanished.

Measured, on PR #3147 whose branch is already deleted

URL formstatusduring reviewafter merge
blob/<branch>/404worksdead
blob/<head-sha>/200worksworks
blob/<merge-sha>/200n/aworks
blob/main/200404works

Only the head SHA works on both sides of the merge. GitHub retains refs/pull/<N>/head forever, so the commit stays reachable even after the branch is gone.
