SessionEnd reports the installed version

The reporter used to look for package.json outside the installed plugin. It now uses the .claude-plugin/plugin.json shipped inside it.

Captured SessionEnd payload

{
  "manifest_version": "10.17.0",
  "hook_version": "0.0.0"
}

Mismatch: the reporter sent its fallback instead of the installed version.

The same probe ran against the built lifecycle bundle in both cases. It intercepted the webhook locally; no request left the process.
