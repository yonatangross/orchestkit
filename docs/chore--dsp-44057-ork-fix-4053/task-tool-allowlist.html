What this PR changes

The earlier CC 2.1.233 wording said task tools were removed for the newest models. The updated notes list Claude 3.x, Opus 4.0 to 4.7, Sonnet 4.0 to 4.6, and Haiku 4.5. They include TodoWrite with the four Task tools.

The flag note retains user or managed settings (or the shell). Plugin settings cannot supply the flag. Granting a tool in agent frontmatter does not make an absent tool available.

This page illustrates the documented rule. It does not inspect a Claude Code session or change any setting.
