A typo that switches off the dist entry cap

The dist sync splits a tree into requests of at most DIST_SYNC_TREE_ENTRIES entries. The value goes through Number(), and a word becomes NaN. No count is ever at or above NaN, so the split never happens and every entry goes in one request, the failure the cap exists to stop. Type a value to compare the old behaviour with the new check. The default stays 300 when the variable is unset.
