Tool presence is the probe model's own report of its tool list. Agent calls and child replies are counted from the stream-json output.

Cause and fix

The guess "a forked agent cannot spawn agents" is refuted: it can. It cannot call Workflow, and the default fan-out of review-pr, verify, assess, audit-full and cover is a Workflow call.

A first fix added a fallback line to each skill. A live run (8a5bd5aa) still did a single pass with 0 Agent calls: the fork judged the PR too small. So, by operator decision, the five skills now run inline (no context: fork), where the Workflow tool exists.

tests/skills/structure/test-workflow-skills-run-inline.mjs fails if any skill that calls Workflow sets context: fork. It fails on all five skills before the change.
