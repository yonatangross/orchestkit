A silent crash is not a missing browser.

The glyph triage gate separates a browser that never launched (environment verdict, skippable outside CI) from one that started and rendered nothing (hard failure). Both leave an empty dom.html, so the classifier keys on a stderr signature, never on absent output. The guard line is [[ -s "$err" ]] || return 1 inside launch_failure_reason: an empty stderr cannot be a launch failure. Proof 5 only grepped for the identifiers, so an edit that made the function succeed on an empty file would have stayed green. Proof 6 runs the stub for real.

What the new proof asserts

printf '#!/bin/sh\nexit 1\n' > "$WORK/silent-fail"   # non-zero, EMPTY stderr

run_gate silent-fail silent-fail "$GATE" -u CI          # outside CI, where a skip would live
status != 0                        hard fail
'produced no DOM' present          case (a), the right failure
no 'ENVIRONMENT UNAVAILABLE'       never classified as a launch failure
no 'SKIP:'                         never skippable, even outside CI

The mutation check that proves the teeth

Change the guard to [[ -s "$err" ]] || { echo "silent"; return 0; } and proof 6 goes red (a silent non-zero exit did not fail) while proofs 1 to 5, including the identifier greps, stay green. That gap is the whole issue.
