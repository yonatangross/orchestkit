secrets-veil shows what it masked, by byte count

If a command prints a token or key, it is covered with dots before Claude reads it, and a toast tells you how much was hidden.

Before

The veil already worked, but silently: the operator saw dots and could not tell which layer made them.

After

After masking, a toast and a status line give the count and the bytes in and out, and a debug line records the whole-result sizes. There is still no reveal path.

Proof

Live 2.1.282: a planted fake ghp_ token reads as 8 x U+2022 with the mod and as 40 characters in a control session without it; toast: masked 1 value in Bash, 40 bytes in, 24 bytes out. Tests 56 passed.

Mods load only with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1; Function Hooks is still an unannounced Claude Code prototype. PR fix/mods-secrets-veil-visible.
