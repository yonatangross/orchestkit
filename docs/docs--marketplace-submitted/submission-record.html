Two corrections this submission surfaced

1 · Target directory

Approved submissions land in anthropics/claude-plugins-community after review, not the official marketplace. Per the Claude Code docs the official marketplace is curated by Anthropic at its discretion, has no application process, and the form does not add plugins to it.

The win here is a community listing. Framing it as "official marketplace" would have set the wrong expectation for anyone reading this later.

2 · Claude Cowork was unticked

The form asks submitters to test each selected surface first. OrchestKit has never been tested in Cowork, and a grep for cowork across plugins/ returns only the word "coworker" in prose.

Ticking it would have been an untested claim on a form that explicitly asks you not to make one. Cowork can be added later via a new submission once actually exercised.

Both corrections share a shape. Each is a claim that would have been convenient to make and was not verifiable: "official marketplace" was an assumption about where approval leads, "Cowork supported" an assumption about a surface never run. The doc records them so the next submission starts from what was checked rather than what was hoped.

Why this PR needed a playground at all

It changes exactly one file, docs/marketplace-submission.md, which looks like the docs-only case the gate skips. It is not: the inert list is only root-level README.md, CHANGELOG.md, CONTRIBUTING.md, SECURITY.md, CODE_OF_CONDUCT.md, LICENSE, .github/**, vercel.json and *.toml. Anything under docs/ is not inert, so the gate fires fail-closed and wants docs/docs--marketplace-submitted/ — a doubled "docs" that reads like a typo and is not, because the slug is the branch name with / replaced by --.
