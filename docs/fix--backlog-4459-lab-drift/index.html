What the fix proves

The build may recreate a missing public copy. An unchanged tracked diff then says nothing about whether that copy was included in the commit. The new guard requires generated Lab copies to be tracked before applying the existing content-drift check.

The regression creates a temporary Git tree, generates a copy, removes it from the index, and generates it again. Removing the new guard reproduces the old false pass. Tracking the copy restores a pass.
