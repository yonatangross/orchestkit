A silent helper failure must block the commit.

The release-bundle guard must check both its helper's exit status and its list of forbidden paths. Empty output alone cannot prove success.


This is a decision-table demonstration, not a live Git hook invocation. Other pre-commit checks can still block a commit that passes this guard.

Delivery checks

  • Reproduce empty-output helper failure.
  • Capture nonzero helper status and increment the hook error count.
  • Exercise the real hook in isolated fixtures.
  • Remove the fix and prove the regression test fails.
  • Review before requesting LAND.
