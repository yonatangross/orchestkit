51 skill scripts get a real syntax + lint gate

Issue #3500. src/skills/**/scripts/ ships 51 Python scripts; the only Python CI jobs cover the hook-contract and orchestkit-py packages, never these. The new step lives in ci.yml's lint job.

The new CI step

python3 -m compileall -q src/skills
python3 -m pip install --quiet "ruff>=0.8.0"
ruff check src/skills

compileall catches syntax errors. ruff runs under the repo pyproject.toml (target py313; **/skills/*/templates and **/skills/*/examples excluded).

What had to be fixed for a green gate

rulecountexample fix
UP01713timezone.utc → datetime.UTC
UP03111"%s" % x → f-string
PTH1xx15open(p) → Path(p).open()
I001 / F4xx17import sort, unused imports/vars
UP042 / UP0474str,Enum → StrEnum, PEP-695 generics
E402 / SIM / B9xx15import order, ternaries, raise ... from, zip(strict=)

Six dead system = """…""" prompt strings in rag-retrieval templates became module-level *_SYSTEM_PROMPT constants instead of being deleted.

Prove the gate bites
