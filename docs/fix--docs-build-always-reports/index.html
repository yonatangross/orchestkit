Docs Site Build always reports

Docs Site Build is a required check on main. When a PR changed no docs-site input, the job was skipped, and a skipped required check never reads as SUCCESS at the merge door. Every weekly traffic-snapshot bot PR (one line in docs/traffic/snapshots.jsonl) was stuck on it.
