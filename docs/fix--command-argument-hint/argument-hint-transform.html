The transform

plugins/ork/commands/visualize-plan.md (before)

generate_command_from_skill() in scripts/build-plugins.sh hand-writes the frontmatter field by field. It extracted description and allowed-tools and nothing else, so any other key the source declares is discarded without a warning. The skill still says argument-hint, every test still passes, and the placeholder simply never appears.
