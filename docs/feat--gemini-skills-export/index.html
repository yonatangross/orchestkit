Export ork skills to the Gemini app

The Gemini app takes a skill as a SKILL.md file, or a folder or .zip with a SKILL.md in its main folder (Gemini Apps Help, answer 17094296). scripts/export-gemini-skills.mjs turns chosen ork skills into one .zip each, and refuses any skill that would not work in a chat app.

What the script checks

RuleWhy
Name is lowercase words joined by hyphens, and matches the folderGemini app rule
Description is 1024 characters or lessGemini app limit
Plain-text files only, no hidden files such as .DS_StoreGemini app upload rules
No MCP tool names, subagent calls, GitHub CLI calls or hook files in the textA chat app has no tools to run them
All zips together under 100 MBGemini app upload limit

The frontmatter is cut to name and description. test-cases.json stays out of the zip; it is for our own grading.
