The regression check

The CI test runs real documentation generators in the order declared by scripts/build-plugins.sh, in a temporary repository. After committing the first result, it runs them again and requires an empty Git status. Restoring the old order must fail.

Docs site data also runs after stamping so its manifest version is current. The interactive model above focuses on the page and search-index dependency.
