Vercel build cuts for docs/site

Try a push and see whether Vercel builds it. Mirrors vercel.json git.deploymentEnabled plus scripts/vercel-ignore.sh.

…
  1. Branch is release-please--** or dependabot/**: deployment disabled
  2. Branch is main: always build
  3. No [preview] in the commit message: skip
  4. No usable previous SHA: build
  5. docs/site unchanged: skip
  6. docs/site changed: build

Request a preview with git commit --allow-empty -m "chore: request preview [preview]" && git push.
