The library first page: server links, a live terminal, host lines

This PR turns the home page library into one flat list of plain links that works without JavaScript, adds a replayed run of one request through the seven stations, and states what each host ships. Everything below is read from the generated data the site uses (library-data.ts), not typed by hand.

1. The list: 303 links, filtered without re-rendering

Every item is a link to its own page. Without JavaScript a station or kind chip is a hash link and CSS shows only that group. With JavaScript the page only hides rows, so the links stay in the document before, during and after a search.

    2. The terminal run: its four states

    One request, /ork:implement, replayed line by line. Each of the 20 lines is a real skill, agent or hook placed at the station where it acts.

    orchestkit run · Claude Code

    3. What each host gets from this run

    One run is shown on every host and named as Claude Code's. The line for the other hosts is computed from the pack manifests (Cursor, Codex, Pi and the skills.sh starter list). Devin is not shown: nothing verifies its count yet.

    Copies your current choices as text a session can act on.
