The check that cost more than the file.

Finding #32 on the Vercel dashboard: inspect-export.mjs accepted archive names of any depth, then its name-clash check rebuilt every prefix with slice/join. A deeply nested GNU long name inside a tiny .tar.gz cost quadratic CPU and stalled the import. The fix caps name bytes (512) and depth (32) in safeName, and the clash check now grows one running prefix instead of rebuilding each level.
