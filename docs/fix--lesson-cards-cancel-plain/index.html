A cancel is not an Error

In lesson-cards 1.0.5 (beta.109), Escape and Cancel already said Cancelled by you; not run., but Claude Code still drew Error: in front and the deny line still carried a Fix: hint. A user cancel is not a failure, and a Fix hint on a cancel is noise. lesson-cards 1.0.6 starts the cancel deny with Cancelled: (Claude Code leaves that prefix alone, same as Error: ) and drops the Fix line. The lesson id stays. Other refuses (no dialog, no exact Proceed anyway) still keep a short Fix for the model.

Claude Code tool-result renderer (2.1.283):
if startsWith("Error: ") or startsWith("Cancelled: ") → leave alone
else → glue "Error: " in front
Error: Cancelled by you; not run. [lesson:git-ls-files-quotepath-blind] Fix: git ls-files -z | tr '\0' '\n' | grep -qxF "$name"
Cancelled: Cancelled by you; not run. [lesson:git-ls-files-quotepath-blind]
