Static evidence, not a live server. Both panes are the first lines of real GET /api/md/getting-started/installation responses from next dev, with the page file saved as LF and as CRLF. ␍ marks a carriage return kept from the file. Long description lines are shortened with "...".

The fix: the frontmatter pattern in stripFrontmatter accepts an optional \r before each fence newline. After it, the CRLF body equals the LF body once line endings are normalized (2,645 characters each). Unterminated fences and pages without frontmatter are still returned unchanged.
