A hook that spawned an unrestricted claude

orchestkit #4906 · session-identity, CC Restricted Smoke

Under claude --restricted, the session-identity hook starts a nested claude -p --model haiku to title the session. Before the fix, that child ran with every built-in tool, Bash and WebFetch included. The smoke only checked the first request it saw, so it caught this about one run in five. Press Run to replay a run in each version.
