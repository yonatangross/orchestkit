Markdown Accept negotiation

A quality of zero means “not acceptable.” The same docs request now gets HTML when it explicitly rejects Markdown.

GET /docs/foundations/overview

Accept: text/html, text/markdown;q=0

Before

200 text/markdown

After

200 text/html
Check Markdown clients and recovery responses
Docs page, Accept: text/markdown
200 text/markdown before and after.
Docs page, Accept: Text/Markdown;Q=0.5
200 text/html before, 200 text/markdown after.
Missing path, Accept: application/json, text/markdown;q=0
404 text/markdown before, 404 application/json after.
Reproduce against a local docs server 
curl -sS -o /dev/null -w '%{http_code} %{content_type}\n' -H 'Accept: text/html, text/markdown;q=0' http://localhost:3000/docs/foundations/overview
