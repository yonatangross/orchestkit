Every session records the plugin version and the rules it ran under

Branch fix/session-stamp-ork-version. Before this change sessions.db had ork_version NULL on 11534 of 11534 rows and no record of the rules a session ran under, so after a bad rule was rolled back nobody could list the sessions it touched. Logic mirrors src/hooks/src/lib/rules-hash.ts and src/hooks/src/lifecycle/session-registrar.ts.

What a session row now records

columnvaluewhen it cannot be read
ork_versionthe version in .claude-plugin/plugin.json (then plugin.json) above the running hook bundleork_version_unresolved + one log line
rules_hashsha256 over CLAUDE.md, its @ imports, rules/**/*.md (sorted) and the active output style, each as path NUL content NULrules_hash_empty + one log line

NULL now means only "row written before migration 006". A failure is never NULL and never the hash of nothing.
