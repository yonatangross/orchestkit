The plugins/ drift reminder no longer stops the turn

After an edit under src/ changes a build input and plugins/ was not rebuilt, the drift hook reminds the model to run npm run build. Pick a version to see what one turn looks like.


  
Why: the edit has already landed when PostToolUse runs, so a block cannot undo it. Claude Code honours continueOnBlock on prompt hooks only, so continue:false from this command hook ended the whole turn mid-task. Detection, the 1-hour snapshot window and the git-timeout rule are unchanged.
