Seven operator skills move to ork-extras, slash-only

Trim stage 1, the moves. Seven skills with no call in 90 days leave core ork for the opt-in ork-extras plugin, the way the first 26 did. Each keeps its source file. Nothing is deleted.

What changed

Slash-only. All seven are hidden from the model, so the ork-extras listing does not grow and core's shrinks. Three of them were user-invocable: false; they are now user-invocable, or nobody could start them.

The workflows stay put. audit-full-mapreduce and skill-fitness stay registered in core, so ork:audit-full-mapreduce and ork:skill-fitness still launch by name.

Self-contained. audit-full carries byte copies of the two core files it used to read through the plugin root. audit-activation finds the core agent catalog next to it when it runs from ork-extras.

Old names. Every ork:<name> reference to a moved skill now says ork-extras:<name>. Install the plugin with /plugin install ork-extras@orchestkit.
