Components

Build and release path

Layers

Plugin content

115 skills, 36 agents, 8 workflow scripts

  • Skills and agents are Markdown with frontmatter, so they ship as plain files and Claude Code loads them without a runtime.
  • One manifest lists what ships, and count tests fail a PR that drifts from it.

Hook runtime

163 hooks over 32 events, one Node runner, split bundles

  • Each event loads only its own bundle, which keeps cold start small on every tool call.
  • Security hooks fail closed: a missing bundle blocks rather than lets a call through.

Local state

sessions.db on node:sqlite, per user

  • Built-in node:sqlite means no native addon to install or rebuild.
  • One file shared by all sessions on the machine lets hooks see siblings and mark crashed ones.

Docs site

Next.js 16 + Fumadocs on Vercel, /api/mcp, search

  • The MCP endpoint is stateless JSON-RPC over the same search the pages use, so agents and readers see one index.
  • A stdio image of the same server serves registries and offline clients.

Release

release-please, tags, stable pin, dist repo, GHCR

  • Stable users install a pinned tag, so main can move without breaking them.
  • A slim dist repo carries only plugins/ork for directory size limits.

Design decisions

Edit src/, ship generated plugins/

Gain One source of truth with a build that assembles real directories Claude Code can load.

Cost Generated files are committed and can drift; CI and count checks must guard them.

One Node runner with per-event split bundles

Gain Small cold start on every hook call.

Cost A broken bundle silences every hook in it until rebuilt.

Security hooks fail closed

Gain A bad install cannot quietly disable command and write guards.

Cost A broken install blocks tool calls until the user rebuilds or reinstalls.

Local SQLite registry on built-in node:sqlite

Gain No native dependency; sessions on one machine share state.

Cost Needs Node 22.5 or newer; unused tables had to be dropped later.

Stable pin plus an alpha entry that tracks main

Gain Stable users get tagged releases; early users opt in to main.

Cost Two marketplace entries and a pin PR on every release.

Public docs API with optional identity

Gain Anonymous reads are the product; agents can still find auth metadata.

Cost More well-known endpoints to keep correct.
