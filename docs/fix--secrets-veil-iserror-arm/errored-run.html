secrets-veil 0.0.9: a failed command keeps its error

On an errored tool run Claude Code sets isError and result is the error text, a string. secrets-veil 0.0.8 masked that string and answered a changed result, which core checked against the tool's object shape and refused, so the model never read the error (48 refusals in 9 days on one machine). 0.0.9 answers a masked error as { deny: masked text }.
