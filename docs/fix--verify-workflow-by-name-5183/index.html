Skills launch plugin workflows by name

verify, assess, review-pr, cover and four other skills started their Phase 2 workflow with a scriptPath into the installed plugin cache. Claude Code refuses a script path the session cannot already read, so a headless claude -p run without --add-dir lost the verdict gate, and verify carried on with plain agents without saying so (#5183). The skills now call Workflow(name="ork:<name>"), and a refused call is named in the report and caps the verdict.
