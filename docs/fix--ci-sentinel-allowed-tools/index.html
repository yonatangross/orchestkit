The sentinel model runs with no tools

ci-sentinel runs claude -p on every red PR, and the model reads untrusted CI logs (fork PRs included) whose verdict is posted as a public comment. Text rules on commands did not hold: a quoted flag, a quote-split $E''NV read, or a gojq @base64 of a secret all passed them. Now the step fetches the checks and failed logs itself with plain gh, and the model only reads that text, with no tools.
