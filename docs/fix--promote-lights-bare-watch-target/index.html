promote-lights: /lights takes a bare watch target

Branch fix/promote-lights-bare-watch-target. Seen on an operator screenshot (2026-10-05, Claude Code inside Herdr on a Windows terminal, repo on branch development): /lights owner/#repo123 answered with the same line as a bare /lights.

Verdict. The /lights handler tested only off, refresh and watch; every other first word fell through to the no-PR hint. Now any other non-empty argument goes through parseWatchTarget: a match starts the watch, a miss gets its own line naming the word. The no-PR hint names the head it looked for and the PROMOTE_HEAD override.
