Isolation guard: prompts that span lines cannot hide a spawn

The isolation guard reads each Agent( call until its parentheses balance. It skipped parentheses inside triple-quoted prompts and inside plain quoted strings on one line. A plain quoted prompt that spans lines was not skipped, so a list marker such as 1) inside it closed the call early and hid a missing isolation. Keys written with spaces around the equals sign were not matched either.

What changed

  • Open strings carry over: the paren counter keeps a flag for a plain quoted string that is still open at the end of a line, and skips text until it closes. Escaped quotes are removed first.
  • Spaces around the equals sign: name, team_name, isolation and run_in_background match with or without them.
  • Mutants still caught: design-import without isolation, a teammate with isolation, Pattern 6 without isolation, and a teammate not told to commit.
  • Stacked: this branch sits on the teammate-check-before-skip change, which adds the scan function these fixtures use.
