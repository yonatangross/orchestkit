Docs search keeps the full result set

limit=5 now means five rows per page, not five matches in total. Follow the cursor to get the next five rows from the same ranked list.

What changed

Fumadocs returns all matches. The route ranks them, sets X-Total-Count, and then slices the page. If more rows remain, it sends X-Next-Cursor. A page size must be an integer from 1 to 100.

How to reproduce

Run against the local Next.js docs server on port 3100. Page 2 used a constructed cursor before the fix and the returned cursor after it.

curl -si 'http://127.0.0.1:3100/api/search?query=install&limit=5&cursor=djE6NQ'
