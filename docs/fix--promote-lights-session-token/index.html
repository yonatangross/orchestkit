A new session never shows old lights

The CI band is kept between redraws in storage that outlives a session, and the band can be drawn before the new session has cleared it. In a recording, a new session showed the previous session's pull request for about three seconds before its own lights arrived.

Each stored entry now carries a token of the session that wrote it, and the band and the /lights command ignore anything written by another session (or by an older version with no token). Tests pin both cases and fail on the previous code.
