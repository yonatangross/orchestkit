Old single pair and new three-round result

Observed in this lane on 2026-09-14: 0ms, 5ms, 27ms; minimum 0ms. The raw first delta was -1ms and was floored to zero. These are host-specific traced observations, not timing guarantees.

Host scheduling noise can inflate either side of a pair. Three rounds and their minimum reduce the effect of isolated interference because it adds time, while real payload work remains present in every round.

This is not a universal statistical guarantee. It is a focused estimator for this short-circuit test, with its existing strict 120ms budget and immediate failure when either hook result is ERROR.
