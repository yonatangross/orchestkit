Pre-commit must accept the restore CI prints.

Issue #4300. The release-owned gate tells you to restore dist from origin/main. Before this fix, that commit had no MERGE_HEAD, so the guard classified tip-equal content as authored.


What the guard asks

  1. If MERGE_HEAD is an ancestor of origin/main and the index matches MERGE_HEAD, inherit.
  2. Else if the index matches refs/remotes/origin/main, inherit (the #4300 path).
  3. Else print the path; pre-commit blocks.

Authored dist that differs from the tip still fails. That half is the hole check.
