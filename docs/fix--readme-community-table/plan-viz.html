The timeline supports reading the omission as deliberate. A 2026-06-21 platform audit praised "The Orchestra" as on-theme during the metaphor era; the 2026-07-17 round then replaced metaphor names with literal ones and did not carry it over. It is absent from the portfolio seeds and from platform's COMMUNITY_ROOMS independently. Two omissions after a three-round naming exercise is a decision, not a gap.

The irony: the README's original label for that invite was "AI Dev (EN)", which passes the doctrine. The first draft of this fix replaced a compliant display name with the non-compliant internal group name. That row was not the stale one. The group stays live and unadvertised, exactly as before this PR; republishing it is a branding decision, not a docs fix.
