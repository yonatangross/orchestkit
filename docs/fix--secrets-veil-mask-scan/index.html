Masking stays fast on long lines

Some long single-line outputs (minified code, repeated tokens) made the masker rescan the same text over and over, which could hold a session for several seconds. The scan now moves past each match instead of restarting inside it, and a single value over a fixed size is withheld rather than scanned.

a repeated key prefix11.0 sunder 200 ms (test bound)
minified text with a prefix inside ordinary words5.1 sunder 200 ms (test bound)

Tests bound both cases at 200 ms, prove repeated values are still masked everywhere, and prove an oversized single value is withheld.
