01 / What self_consistent_answer sends



Two separate flags. model_thinks controls only the CoT suffix. accepts_sampling controls only temperature: current Claude models (Opus 5.5, Opus 5, Opus 4.8/4.7, Sonnet 5, Fable 5/5.1) return 400 on temperature, top_p and top_k even with thinking off (claude-api skill, Thinking and Effort table), so it defaults to False. Path diversity there comes from independent calls and effort.
