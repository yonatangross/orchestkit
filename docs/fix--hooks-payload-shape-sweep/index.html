Estate sweep T1. CC sends tool_response on PostToolUse, never tool_output; Skill inputs arrive as ork:<name>; and a session-state read outside the lock lost parallel agent entries. Each fix was proven fail-first at origin/main, then verified green.

Before (origin/main)

  read input.tool_output (never sent)
  → last_commit/push/pr = null

auto-verify + 2 expect hooks
  skill === 'expect' && tool_output
  → ork:expect never matched

recordAgentStart
  read outside the lock
  → parallel SubagentStart lost ids

After (this PR)

  → scans {stdout, stderr} for real

  → fires on the real payload

  → lock covers read+modify+write

  logs new URL(u).host only
  → '<unparseable-url>' fallback
