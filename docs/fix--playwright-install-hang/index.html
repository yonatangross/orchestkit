Docs Site Build: a Playwright install that cannot hang

Issue #4665. Three required Docs Site Build runs on 2026-10-07 hung in the Playwright install until they were cancelled. All three stopped in apt, before any browser download.

Where each run stopped

JobLast line before the hangSilent for
112950356919Get:5 archive.ubuntu.com noble-security InRelease 20 min 23 s
112961977648Get:6 archive.ubuntu.com noble-security InRelease 20 min 53 s
113017086059Get:5 archive.ubuntu.com noble-security InRelease 20 min 11 s

Each time the Azure Ubuntu mirror stopped answering (a run of Ign: lines), apt fell back to archive.ubuntu.com, and then waited with no timeout. A browser cache alone would not have helped: the browser download never started.

The fix in docs.yml

Before
npx playwright install --with-deps chromium     (no step timeout)
After
Read Playwright version        -> cache key playwright-Linux-1.63.0
Cache Playwright browsers      ~/.cache/ms-playwright
Bound apt network waits        Acquire::http(s)::Timeout 20, Retries 2
Install Playwright system deps timeout-minutes 5, 2 attempts x timeout 120
Install Playwright Chromium    cache miss only, same bounds

A dead mirror now fails in seconds, a stuck attempt is killed at 2 minutes and retried once, and the job fails visibly within 5 minutes instead of eating its 25-minute budget.

The guard

tests/ci/test-docs-playwright-install-bounded.mjs fails if the cache, the apt timeouts, the step caps or the retry disappear, or if the combined install --with-deps comes back. It failed 6 checks on the old docs.yml.
