The npm audit gate judges the change

A moderate advisory in a package nobody touched used to block every push for hours. Now the scheduled whole-tree audit owns the whole tree, and the hook and the pull request checks judge only what the change does. This page is the gate's decision table: pick an event and a situation to see the verdict.

Scope. One script, .github/scripts/audit-gate.sh, decides for the pre-push hook, Security Tests and Dependency Audit. The event picks the mode: a pull request or the hook narrows to the change, every other event stays whole-tree. High and critical advisories fail everywhere.
