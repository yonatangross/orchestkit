Malformed JSON is not an empty query

The missing closing brace used to produce the same response as an empty POST.

POST /ask?limit=1
Content-Type: application/json
{"query":"hooks"

Before: local main

HTTP 200

{
  "query": "",
  "results": [],
  "_meta": { "response_type": "list", "version": "0.1",
             "count": 0, "usage": "Provide a `query` …" }
}

Readiness envelope excerpt; the usage hint is shortened.

After: fix branch

HTTP 400

{
  "type": "about:blank",
  "title": "Invalid JSON body",
  "status": 400,
  "detail": "The request body must contain valid JSON.",
  "instance": "/ask"
}

Structured error in the same format as other /ask errors.
