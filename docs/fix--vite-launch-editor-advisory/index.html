Pushes pass the audit gate again

On 2026-10-21 a new npm advisory set (one high, two moderate) landed on the copy of launch-editor that vite ships inside it. The repository's audit gate checks 11 package trees before every push, and 7 of them pulled in an affected vite through vitest, so every push in the repository was refused. This change moves vite to 8.3.4 in those 7 lockfiles. It changes no package.json and no code.

Treevite beforevite after
docs/site8.2.28.3.4
hook-contract generic-client example8.2.28.3.4
mods: lesson-cards, memory-lens, promote-lights, prompt-enhancer, secrets-veil8.3.08.3.4

Audit gate: 4 of 11 trees passed before, 11 of 11 after. What else moved, checked by a script against main: in every tree, the packages vite itself depends on (rolldown and its platform builds, the oxc types, postcss, nanoid); in the hook-contract example, the lockfile's record of the local hook-contract package now lists the dev version ranges that hook-contract's package.json already declares (no installed version changes from that). vite is a test tool here: the docs site build does not use it.
