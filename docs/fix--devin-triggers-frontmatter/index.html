Devin now loads all 107 skills

Issue #4147. Devin's plugin loader silently dropped any skill whose SKILL.md frontmatter carried an object-shaped triggers key (keywords/examples/anti-triggers): 76 of 107 listed, and all 31 missing ones had exactly that shape. scripts/build-plugins.sh now deletes the triggers block from the generated plugins/ork/skills/*/SKILL.md only, inside the frontmatter fence. The authoring format in src/skills is untouched, and every consumer of the key reads the source.

local build

devin plugins info against the previously installed plugin listed 76 skills. A machine-local install of this branch's plugins/ork listed all 107, then the temporary install was removed.

Why dropping was safe

precondition: grep the built-tree readers
  hooks read path_patterns, tags, names   (never triggers)
  Cursor command wrappers                 (triggers was never forwarded)
  skill-indexes generator                 (reads tags only)
  codex plugin skills                     (0 triggers keys)

consumers of triggers, all read src/skills:
  scripts/eval/eval-coverage.sh
  tests/skills/triggering/test-trigger-keywords.sh
  tests/skills/triggering/test-skill-coverage.sh
  tests/plugins/test-command-frontmatter-passthrough.sh
  tests/evals/skills/*

Renaming to x-triggers was considered and rejected: the frontmatter-passthrough test enumerates keys on the built SKILL.md and fails on any unclassified one. Dropping keeps that test, and all others, byte-for-byte unchanged.
