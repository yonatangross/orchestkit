One rules file, written once per project dir

SessionStart materialization for antipatterns.md. Rules files ride the prompt cache, but they are not free: every copy is injected into every prompt.

The defect

materializeAntipatternRules(projectDir) wrote the same static content to <project>/.claude/rules/antipatterns.md on every session start, for every project dir. With a byte-identical copy already at ~/.claude/rules/ (the user-global scope), each project dir added one more copy of the same text to the prompt.

~/.claude/rules/antipatterns.md            injected once (user scope)
<proj A>/.claude/rules/antipatterns.md    identical copy, injected again
<proj B>/.claude/rules/antipatterns.md    identical copy, injected again
<proj C>/.claude/rules/antipatterns.md    identical copy, injected again
