Two green PRs, one red main

Each install command PR passed its 18 required checks. Merged in sequence, they left Docs Site Build red on main, because that check is not required and the two PRs added tests that cannot both pass.

Step through the chain

The fix

One assertion in docs/site/__tests__/landing-page.test.tsx now names the label the hero button renders from SITE.installCommand:

name: "Copy claude plugin marketplace add yonatangross/orchestkit && claude plugin install ork@orchestkit to clipboard"

Lesson

  • A serial chain that is green per PR can still break main when a later PR adds a test the earlier one violates and the failing check is not required.
  • After a chain lands, read the non required checks at the new main tip too.
