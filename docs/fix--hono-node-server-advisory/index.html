Why behaviour does not change

The package arrives only through @modelcontextprotocol/sdk, whose range is ^1.19.9 || ^2.0.5, so a lockfile refresh was enough. The MCP server runs over stdio (src/docs-server.ts uses StdioServerTransport). Nothing in src/mcp-server imports the SDK's HTTP transport, which is the only caller of @hono/node-server, and serveStatic, the vulnerable function, is not used anywhere. The server is not exposed at runtime; the bump clears the audit gate.
