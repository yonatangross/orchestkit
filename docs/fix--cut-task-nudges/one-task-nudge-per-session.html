One task-tracking nudge per session

Three hooks could each tell the model to use task tracking. Before, each decided alone. After, they share one per-session claim: the first hook to fire may nudge, the other two stay silent. Click through a session below and watch both versions react to the same events.

01 / Drive a session

Explore is on the exempt list in both agent hooks, so it never nudges in either version. Agent types are registered locally on their first PostToolUse, so a second spawn of the same type finds a task and stays quiet in both versions.

      02 / What each hook does

      HookEventBeforeAfter
      [task-nudge] multi-step-task-nudgeUserPromptSubmit Throttled by a per-session counter: full nudge on the 1st qualifying prompt, a final conditional line on the 3rd, silent after. Silent once the session has a task. Counter still advances. Text needs the shared nudge unspent, and it is spent only when the dispatcher delivers it. An explicit todo-list ask bypasses the limit.
      [Task Tracking] task-existence-gatePreToolUse (Agent) Nudges on every non-exempt spawn whose agent type has no registered task, even if the session already has a task. Same condition, then needs the shared nudge unspent. A later permission ask discards the text and leaves it unspent.
      [Auto-Task] agent-task-auto-registerPostToolUse (Agent) Registers the agent, then nudges unless the agent is background. Registers each eligible agent (a named, non-exempt type with no registration yet). Nudge text must win the shared claim.

      The claim is an exclusive-create marker file named <session>-task-nudge.sent. It is written when the text is delivered, so a dropped nudge stays unspent. Parallel Agent spawns cannot both win. No nudge once the session has a task, none without a session id, and none on any filesystem error (fail closed).

      03 / Not changed, and one limit

      Unchanged: registerTask still runs for every eligible agent, and the qualifying-prompt counter read by the Stop hook still advances. Limit: hook input has no tool list, so a session without TaskCreate (such as the desktop app) still gets the one reminder. Its wording is conditional on the tool being available. This page simulates the logic from the diff and its tests; it does not run the hooks.
