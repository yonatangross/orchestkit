Installer regression / shared hook paths

Hook paths without broken links.

Copying hooks into Git's resolved directory can replace tracked files with self-symlinks after prepare. Shared hooks can also point into a deleted worktree. Configure a relative core.hooksPath instead, just like the repository's prepare script.

Static evidence, not a live shell. Before captures both failures on merged main (70f5b8333). After shows real revised-installer output for a normal clone and linked worktree. The regression test verifies that tracked hooks remain unchanged and main checkout hooks survive worktree removal.

The fix: git config --local core.hooksPath bin/git-hooks. No copying, symlinks or backups. Each checkout uses its own tracked hooks, even after a linked worktree is removed. Isolated tests cover global configuration, prepare-style configuration and repeated installation without modifying hook files.
