Old review-pr docs URLs keep working

The docs build writes a skill page as a folder (the page plus references and rules pages) only while the page is over 90000 bytes. The shorter review-pr text puts it at 89806 bytes, so the build now writes one page, and the two sub-URLs that people have bookmarked would answer 404. A permanent redirect sends each of them to the page.
