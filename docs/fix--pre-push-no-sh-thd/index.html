Pre-push: no sh-thd-* in the repo root

Branch fix/pre-push-no-sh-thd, closes #5009. Bash here-strings were writing empty temp files into the worktree whenever TMPDIR was the repository root.

What changed

Why it happened

  • The hook cds to the repository root, then uses <<< here-strings.
  • Bash writes those as sh-thd-<digits> under $TMPDIR.
  • When the agent sandbox makes /tmp unusable, bash falls back to DEFAULT_TMPDIR ".", which is the repo root.
