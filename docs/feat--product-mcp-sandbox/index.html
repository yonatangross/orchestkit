OrchestKit Actions MCP is a read-only Model Context Protocol server that exposes non-destructive CLI actions. Use this page to test the three tools: discover skills, plan installs, and validate configs. No installation required.

POST /api/mcp/actions

JSON-RPC 2.0 over Streamable HTTP. All tools are read-only by construction.

orchestkit_list_skills

List user-invocable skills with names, descriptions, and documentation URLs.

readOnlyHint: true destructiveHint: false

orchestkit_install_plan

Generate install and invocation commands for user-invocable skills or goals. Returns a plan; executes nothing.

readOnlyHint: true destructiveHint: false

orchestkit_doctor_check

Run basic checks on a pasted JSON object configuration fragment. It does not parse YAML and reads only the input.

readOnlyHint: true destructiveHint: false
