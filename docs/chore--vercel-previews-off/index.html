Why it works

Vercel evaluates git.deploymentEnabled rules with minimatch; a branch matching any true rule deploys. Unlisted branches defaulted to true, so every push built a preview. "main": true keeps the production branch deploying, the release-please and dependabot rules stay, and "**": false now covers every other branch, including slash names a single star would miss.
