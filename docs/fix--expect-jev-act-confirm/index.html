EXPECT ACT MODE · #4745

Jev may drive the step only when it agrees, or you confirm

In /ork:expect act mode, Jev picks the next browser action from the page's ARIA snapshot. Page content is untrusted, so a crafted page could steer that pick. Before this fix, any Jev pick above act_confidence_floor ran, even when it disagreed with the agent's own pick. Now a disagreement runs only when the step passes --confirm-disagreement; otherwise the agent's pick runs and the disagreement is logged.
