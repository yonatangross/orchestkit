PR #4581 changes the YAML shape. It keeps the commands, matchers and once values.

Select a shape to see the effect on both hooks. This is a model of the measured Claude Code behavior. It does not run a hook.





[1] Changes
14 skills. 19 matcher groups. 17 unique handlers. The validator parses skill and agent frontmatter as YAML. It rejects a command on a matcher item, an empty handler list, and a handler without type.
All text outside the 14 hook blocks stays unchanged. Two handler lists in implement use compact YAML sequences to stay below the repo line limit.


[2] Execution evidence
The new check fails on all 19 flat items on the base. It passes after conversion. The flat and nested fixtures use the same parser. Eight code mutations made the fixture test fail.
Build, typecheck and security tests pass. Vitest passed 7,468 tests, with two skipped. The PR body has the full check output and handler table.


[3] Risks
Each handler ran once through the built runner. All 17 returned exit code 0. Three took more than 500 ms: issue context, PR context and quality baseline. This PR leaves their code unchanged.
A small fixture can produce silent output. That result does not prove the handler will return useful context in a real session.
