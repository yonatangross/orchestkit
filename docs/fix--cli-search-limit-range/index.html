CLI regression / live API evidence

Search returns the limit you ask for

The docs API accepts limits from 1 to 100. The old CLI sent 50 when asked for 80, and sent 1 when asked for 0.

API control: /api/search?query=hooks&limit=80 returned 80 results.

$ orchestkit search hooks --limit 80 --json
50 results (exit 0)

$ orchestkit search hooks --limit 0 --json
1 result (exit 0)

Recorded runs against orchestkit.dev. JSON output is summarized by result count; error messages are shown verbatim. This page does not run the CLI.
