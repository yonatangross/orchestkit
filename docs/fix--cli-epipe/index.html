OrchestKit / CLI bug fix

One line, then a quiet exit.

After head -n 1 reads the first line, it closes its end of the pipe. The built CLI now treats that broken stdout pipe as normal rather than crashing with an uncaught error.

node --import ./packages/cli/tests/fixtures/fetch-stub.mjs ./packages/cli/dist/cli.js read long-output --base-url https://fixture.test | head -n 1
