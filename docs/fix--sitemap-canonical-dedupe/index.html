Docs SEO / route evidence

One canonical changelog in the sitemap

The sitemap listed the changelog twice under different URLs. It now lists only the URL named by the docs page’s canonical tag.

Before

355 sitemap URLs

  • Canonicalhttps://orchestkit.dev/changelog
  • Aliashttps://orchestkit.dev/docs/changelog

After

354 sitemap URLs

  • Canonicalhttps://orchestkit.dev/changelog
How this was measured

Both local Next.js responses to GET /sitemap.xml returned HTTP 200. Comparing the XML showed one removed URL, zero added URLs, and no changes to the remaining entries or their order.
