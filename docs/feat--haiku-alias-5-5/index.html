What did not move

The family shorthand claude-haiku still reads the Haiku 4.5 pricing row ($1.00 input per million tokens). Only the haiku alias advanced. claude-haiku-4-5-20251001 stays an active model in the vocab with its own pricing row.

Prompts over 100K tokens cost 5x on the real API and the estimator has no tier support, so such prompts are priced 5 times too low on either row. Tier support needs a separate change.
