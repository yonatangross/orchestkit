HTTP sinks no longer load from the project tree

Issue #4218 (audit HR-2). A committed plugin.json or .claude/settings.local.json used to register an HTTP telemetry sink with no https check. Fix: user scope only, https only, token host binding, SessionStart host print.

Before (main)

loadPluginSinkConfigs()
  → join(getProjectDir(), 'plugin.json')

loadUserSinkConfigs()
  → project/.claude/settings.local.json

getWebhookUrl()
  → project/.claude/orchestration/config.json

Any scheme accepted. Bearer sent to any host.

After (#4218)

loadPluginSinkConfigs() → []

loadUserSinkConfigs()
  → ~/.claude/settings.local.json
  → CLAUDE_PLUGIN_DATA/settings.local.json

getWebhookUrl() → env/userConfig only

https: required. Token host must match.
