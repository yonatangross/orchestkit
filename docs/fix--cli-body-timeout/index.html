Headers are not the finish line.

A server can send HTTP 200 and a partial body, then stop. The CLI deadline must stay active until JSON or Markdown finishes reading.

Compare the lifetime

This offline model does not make network requests. Select a version to inspect its timeout boundary.

0s: request starts, timer starts
Headers arrive: timer cleared
Body stalls: no deadline remains
30s: external timeout kills the CLI (exit 124)

Recorded real CLI evidence

A local HTTP server sent a JSON header and an incomplete array, without ending the response. The actual built CLI used its default 15 second deadline.

Before

CLI exit=124 elapsed=30.01s

After

Error: This operation was aborted
CLI exit=1 elapsed=15.04s

Both JSON and Markdown regression tests failed with Test timed out in 2000ms. before the fix. Afterward, all 61 CLI tests passed and the CLI typecheck completed successfully.

One deadline, including the body

The request helper awaits a body reader inside its try block. Its finally block clears the timer after reading or failing. Existing HTTP error handling stays unchanged.

Try with a local stalling server at port 3000:

ORCHESTKIT_BASE_URL=http://127.0.0.1:3000 timeout 30 node packages/cli/dist/cli.js search overview
