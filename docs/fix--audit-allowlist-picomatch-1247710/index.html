One entry is added to .claude/audit-allowlist.json. No lockfile, script or workflow changes. The entry stops being honored by date, and it is removed as soon as a fixed picomatch version ships.

1 / The advisory and the entry

npm advisory 1247710 is GHSA-fc5q-39xc-vjpf, severity high: picomatch is vulnerable to ReDoS through single-branch repeated extglobs. The vulnerable range is <= 4.0.7 and 4.0.7 is the latest published version, so no patched release exists and no lockfile update can clear it today.

The audit gate fails on a high advisory anywhere in the tree. The allowlist is keyed by the numeric npm advisory id, because that is the value the gate compares.
