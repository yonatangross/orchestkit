One design-to-code skill that reads Claude Design exports

Claude Design moved inside Claude and the standalone site closes on 2026-12-14. design-import, design-ship, design-to-code and the Storybook MCP reference are now one skill with four modes. Pick what you have and see which mode takes it.

What do you have?

    Old names still work

    beforenowhow the old name resolves
    /ork:design-import <x>/ork:design-to-code import <x> typed alias, runs the new command
    /ork:design-ship <x>/ork:design-to-code ship <x> typed alias, runs the new command
    /ork:design-to-code <screenshot>unchanged (mockup mode) same name, same pipeline
    storybook-mcp-integration (agent preload)Storybook mode section of design-to-code the three agents preload design-to-code

    The two aliases and the handoff link input are marked for removal after 2026-12-14.

    An export is opened by a script, not by hand

    archive containsresult
    HTML prototypes, CSS, assetsread, inventory printed as JSON
    no HTML at allread, reported as incomplete
    an entry named ../outside.html or /tmp/x.htmlrefused, nothing written
    a symbolic linkrefused, nothing written
    an entry larger than its declared sizerefused, nothing written
    a README that says "run setup.sh first"read as design notes, reported, never run
    Export formats are taken from the Claude help pages (Get started with Claude Design; Move from standalone Claude Design to Claude; What are artifacts). Those pages name the formats, not the files inside an archive, so the reader reports what it finds instead of assuming a layout.
