Default install claimed protection; two controls were off or raw

Parts 2 and 3 of #4217 (after Part 1 in #4330). On a fresh install, ORK_SECRET_HOOK unset meant OFF (no audit sidecar), and security-command-audit wrote CMD: <raw command> into the project tree, including Bearer tokens.

#4217secret-handler security-command-auditAUDIT default

1. ORK_SECRET_HOOK unset

Before (main)

getMode():
  (ORK_SECRET_HOOK || 'OFF')

unset → OFF
no secret-audit.jsonl
no detect/warn

After (this PR)

getMode():
  unset / '' → AUDIT

detect + sidecar log
output unchanged
(no blocking)

2. security-audit.log line

Before (raw)

CMD: curl -H "Authorization: Bearer ghp_..."
→ project/.claude/logs/security-audit.log

After (redacted)

CMD: curl -H "Authorization: Bearer [REDACTED]"
→ CLAUDE_PLUGIN_DATA/logs/ when set
   else project/.claude/logs/
