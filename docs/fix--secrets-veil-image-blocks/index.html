Image reads work again

With secrets-veil on, every Read of a PNG or JPEG came back as "media removed, rejected by API". An image travels as one long base64 string, and that string looks exactly like a high-entropy secret token, so the veil covered it with dots and the API could not decode it. Version 0.0.7 lets the payload of a real image through unchanged and keeps masking everything else.

What the veil still cannot do: it does not see inside an image, so a secret drawn in the pixels or kept in the image metadata reaches the model. Any tool that returns a result shaped like an image block gets the same pass.
