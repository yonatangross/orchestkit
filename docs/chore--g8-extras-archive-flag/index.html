25 ork-extras skills flagged as archive candidates, nothing moved

One frontmatter field is added to 25 skills of the opt-in ork-extras pack. It is a flag only: no skill is moved, renamed, removed or hidden, no description changes, and the pack manifest is unchanged.

1 / The flag

metadata: archive-candidate: "pending an outside usage signal"

A skill is archived, if ever, only after a usage signal from outside this repository exists. Until then the flag changes nothing at run time. The core listing total is unchanged, since the field is not part of the listed description, and no skill count changes.

2 / Which skills carry it

Not flagged: design-stylecards, the 26th skill of the pack, which has logged use.

3 / Why a flag and not a move

The pack shipped inside the core plugin until it was split out, and it is now an opt-in install. Usage logs on one machine therefore cannot see it, so a count of zero there is not evidence the skills are unused. The flag records that these are the first candidates to review and states the bar for acting on it, without removing anything an outside user may rely on.

Not verified: which skills have outside users. No usage signal from outside the repository was available, which is the point of the flag. The group is read as all pack skills except design-stylecards. If only the library skills should carry the flag, drop the 9 domain guides.
