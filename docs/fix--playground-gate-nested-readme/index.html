Why it was wrong

The inert list anchored every entry at the repo root, so README.md matched only the top level file. A two line registry entry in src/hooks/README.md, plus its byte identical copy under plugins/, was treated as a user facing change. The pattern is now (.*/)?README\.md and (.*/)?CHANGELOG\.md. Every other inert entry keeps its root anchor, and a mixed diff is still decided by its non inert file.
