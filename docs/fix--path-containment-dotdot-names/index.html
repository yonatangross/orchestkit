PermissionDenied / Write retry

When two dots are part of the name

..cache is an ordinary directory name. A denied write there can be retried just like a denied write to src. Only the exact .. path segment means “parent directory.”

Each run sent a denied Write event for a real fixture file to the built dispatcher. “Retry” means it returned retry: true; the probe did not perform the denied write.
