The install the card ships

Project scope: agy reads <workspace>/.agents/skills, the same convention Muse Code and OpenCode ride, so the shared skills.sh starter is the line. No ork-agy pack.

Honest gaps

1. skills add -g lands in ~/.agents/skills, which agy never reads. Global agy skills live under ~/.gemini/config/skills or ~/.gemini/skills.
2. Print mode registers a workspace from an absolute --add-dir only. The TUI uses the launch directory, so the interactive lane needs no flag.
3. None of ork's 171 hooks port: agy hooks.json is a different schema (its own event names, camelCase payloads), and agy plugin validate plugins/ork reports hooks skipped.
4. Repo .mcp.json is never read. Shipping a server means a plugin mcp_config.json, which was marker-verified end to end.
5. ork's .cursor-plugin/commands/*.md wrappers do not load. Invoke skills as /<skill-name>, or ork:<name> after a plugin install.
