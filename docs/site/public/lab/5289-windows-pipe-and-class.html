Windows: redirect agent-browser, do not pipe it

Piped: hangs. Redirected: returns.

Before and after

Before (output goes into a pipe):

agent-browser open "$URL" 2>&1 \
  | tail -3

Never returns.

In Git Bash on Windows the daemon starts from this command and keeps the pipe open, so tail never sees end of file, and a timeout does not change that.

Now (output goes to a file, stdin is closed):

agent-browser open "$URL" \
  > ab.out 2>&1 < /dev/null
tail -c 300 ab.out

Returns, then the file is read.

The daemon holds nothing the shell waits on. A bare open about:blank in a call of its own works too.

Doctor check: try a version

doctor is the plugin's health check. It now warns when the installed agent-browser is older than the minimum.
