Draining the density ratchet to zero

#4072 put an information-density floor of 0.20 under every fenced ASCII block in src/skills/**/SKILL.md and, because five existing blocks sat below it, carried a shrinking baseline of allowances. #4073 asks for those five blocks to be drained. This PR reworks the art of all five and empties the baseline: schema header only, total 0, and the gate still exits 0.

Density is info / (info + box + ws) where info counts [A-Za-z0-9→←↑↓], box counts U+2500-U+257F, and ws counts whitespace. The meter below runs the exact formula from tests/unit/test-ascii-density.sh on any block you paste or pick.
