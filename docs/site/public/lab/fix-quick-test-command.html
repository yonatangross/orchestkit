OrchestKit / PR #5311 / argument forwarding

Two hyphens.
The right test suite.

The quick-test flag belongs to the test runner, not npm. Put an argument separator between them.

Compare the captured runs

After / quick mode

npm test -- --quick

npm → argument separator → runner receives --quick

> orchestkit@10.15.1 test
> bash tests/run-all-tests.sh --quick

The runner sees --quick and skips integration, E2E, and performance tests.

Before / default full-suite mode

npm test --quick

npm consumes --quick → runner receives no arguments

npm warn Unknown cli config "--quick". This will stop working in the next major version of npm.

> orchestkit@10.15.1 test
> bash tests/run-all-tests.sh

npm treats --quick as its own configuration flag. The runner starts with its default full-suite settings.

The separator -- tells npm to pass the remaining arguments to its script. Only the documented invocation changes; test-runner code is unchanged.

Evidence: Node v24.22.3, npm 11.19.1. Both runs used env -u DISPLAY from the repo root. Captured startup output proves forwarding, not suite success. The full run was stopped after 25 seconds and the quick run after 180 seconds; neither completed.
