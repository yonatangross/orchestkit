The Gate That Could Not Count Past 300

The PR Playground gate asks GitHub which files a pull request changes, then decides whether a playground is required. It asked through the PR diff, and GitHub refuses a diff past 300 files. Move the slider to see what each version of the gate decides.

574

The red tick marks 300 files, GitHub's diff limit. 574 is the graveyard prune in #4965.

Before: reads the PR diff

gh pr diff N, name-only

After: reads the PR files API

gh api, paginated: repos/OWNER/REPO/pulls/N/files?per_page=100

The files API returns 100 files per page and lists up to 3000. A failed call still leaves the list empty, and an empty list still fails closed, now with the error printed as a warning.
