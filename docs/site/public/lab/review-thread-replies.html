Review threads replied

Verdict: a PR fails while any review thread a bot started (CodeRabbit, Codex, any [bot] author) has no reply from a person or agent, resolved or not. A resolved bot thread with no reply is a silent resolve.

PR 4864, branch feat/review-thread-replies. Operator word GROK-REVIEW-2121, items 1 and 2.

The rule (item 1)

Reply in the thread with the fix commit link, the file:line and the test, or with won't-fix and the reason. Resolve only after the fix is verified. A bot replying to a bot is not a reply.

The check (item 2)

Exit 0 when every bot thread has a reply, 1 when any has none (each listed with file:line, bot, state and link), 2 when the threads cannot be read. It reruns on pushes, new reviews and replies, and runs the script from the base branch, so a PR cannot weaken its own gate.
