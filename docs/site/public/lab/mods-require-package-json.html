ORCHESTKIT LAB · ISSUE 4182

A Silent Skip in the Mods Job

The Mods job in ci.yml typechecks and tests every directory under mods/. If a mod has no package.json, the else branch only echoed and moved on: zero tests ran and the job stayed green. A mod that forgot its whole test surface would pass CI forever.

The one-branch change

before: echo "no package.json, skipping typecheck and tests"
after: echo "::error::mod $name has no package.json; every mod must declare its typecheck and test surface (#4182)" plus status=1, so the step fails and the annotation names the offending mod.

Nothing else in the workflow changed: two inserted lines, one replaced line.

The measurement

Measured on origin/main before the change. All three mods declare a package.json, so the new error branch fires only on a future mod that forgets its surface, never on the current tree.

Run the extracted step against a fixture tree

The step's run block was extracted verbatim and run with shims for claude, npm and npx. Fixture A is the mods tree as is. Fixture B drops one package.json. The mutation runs the old else branch on fixture B.

waiting: three cases, one expectation each

The change is CI-only: the else branch of one step in one workflow. No skill, agent, hook or plugin bytes move.
