POST /ask
Content-Type: application/json
{"query":{"text":7}}

Before · main

HTTP 500

(empty body)

After · fix branch

HTTP 400

{
  "type": "about:blank",
  "title": "Invalid query",
  "status": 400,
  "detail": "`query` must be a string or an object with a string `text`; `q` and `question` must be strings.",
  "instance": "/ask"
}

Control: a valid string still works

{"query":{"text":"hooks"}} returned HTTP 200 and 10 results before and after.

Recorded with curl against local Next.js, first on the unchanged main code and then with the fix applied. The production baseline matched: HTTP 500 for the number, HTTP 200 for the string. This page does not make live /ask requests.
