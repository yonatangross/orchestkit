lesson-cards draws its card and asks before a block lesson

When Claude is about to run something the team already learned the hard way, a card with the lesson appears under that command, and for the serious ones it asks you "Proceed anyway?" first.

Before

On CC 2.1.282 tool.call and ui.render both fired for the exact tool id, yet no card drew: the mod pushed a plain { type: 'Box' } object into the tree next(e) returns, which is an opaque engine node.

After

The card is built from $.ui.resolve(e) elements and wrapped beside the row. A block lesson asks through $.ui.ask; Cancel answers { deny }, so the call never runs and the model reads the lesson as the reason.

Proof

Live 2.1.282: a yellow card under echo pgvector/pgvector:pg16; a red card and the question under git ls-files mods | grep register; debug log line resolved by a hooks module (deny: lesson-cards: the user chose Cancel ...). Tests 51 passed.

Mods load only with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1; Function Hooks is still an unannounced Claude Code prototype. PR fix/mods-lesson-cards-visible.
