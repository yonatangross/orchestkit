PostHog waits for consent on the docs site

Branch fix/docs-posthog-consent, 2026-11-07. Before this change the docs site imported posthog-js and started it on every page load, and the privacy page said there was no consent prompt. Now nothing PostHog loads until a visitor presses "Allow analytics" in a banner.

What did not change

  • The site's own /api/analytics keeps working without the banner: it sets no cookie and is the system of record.
  • Session replay still runs on /docs/reference/* only, and only once PostHog has loaded.
  • Decline and Allow have the same styling, so declining is as easy as allowing.
