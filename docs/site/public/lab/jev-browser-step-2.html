Jev act mode: the pick that drives the step

The Jev step judge now has three modes. Off stays off. Shadow logs a second opinion and never drives. Act lets the Jev pick drive the step, and every failure path falls back to the agent's own pick. The fallback is fail-closed: a dead Jev lane degrades to exactly today's behaviour.

The run summary

At the end of a run, report.sh prints one line and folds the same totals into the JSON report:

JEV_RUN|steps=8|picks=6|fallbacks=2|agree_rate=75.0%

What leaves is unchanged

Act mode sends the same bounded payload as shadow: the step goal, the last verify result, and up to 60 elements as ref / role / accessible-name triples, JSON-escape-decoded and secret-redacted first. No page text beyond names, no cookies, no tokens, no URLs, no full command lines.

Modes resolve in scripts/jev-shadow.sh and jev_shadow.py: ORK_EXPECT_JEV=1|act drives, =shadow logs, unset or falsey is off; a truthy ORK_EXPECT_JEV_SHADOW still selects shadow. Covered by tests/unit/test-expect-jev-shadow.sh.
