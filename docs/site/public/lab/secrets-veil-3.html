Secrets Veil: three layers between the tool and the model

When a tool prints a secret, the model should never read it. The veil arms at session.start and rewrites every tool result before the model sees it. This page runs the same three layers in your browser: values named by a vendor variable, value shapes, and high-entropy tokens. Everything is synthetic.

1. Arm a named value

    Values under 8 characters are not kept: the layer refuses to arm on trivia. The mod reads 21 vendor names, one literal call site each, and nothing else. There is no reveal path: what is covered stays covered.

    2. Tool output goes in

    A 40-char git sha, a 64-char hash, a UUID and a long path must survive untouched: agents read git output constantly. The entropy bar is 4.3 bits per char, and hex can never reach it: 16 symbols cap at log2(16) = 4.0, a UUID at log2(17) = 4.09. That guarantee is counting, not luck.
