lesson-cards 1.2.0: lessons are advisory, never blocking

Operator word 2026-10-21: lessons must never block. Before 1.2.0 a block-severity pattern opened a Proceed anyway? dialog and refused the call with { deny } on Cancel, Escape, a typed answer, or a headless session. From 1.2.0 every match draws the card, adds the lesson to the model context, and the call runs. A block lesson's context is marked BLOCK-SEVERITY LESSON (advisory, not enforced):. The matching hq-ext change is Yonatan-HQ/hq-ext-plugin#2449.
