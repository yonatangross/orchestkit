Escape reads as cancelled by you

In lesson-cards 1.0.4 (beta.107), pressing Escape on the Proceed anyway question printed Not run: no dialog to confirm., as if no dialog had opened. The mod matched only the text the dialog was dismissed, but a live probe on Claude Code 2.1.283 shows Escape throws Claude Code's tool rejection text instead. That dismiss text is only the fallback for a dialog that returns no text. Now both read as Cancelled by you; not run., and every other throw (a host deny, a refused dialog, no dialog at all) still reads Not run: no dialog to confirm.
