Worktree tooling / Regression evidence

Worktree reclaim reads paths with newlines

bin/worktree-reclaim.sh now reads git worktree list --porcelain -z and splits records on NUL. A main or linked worktree path that contains a newline stays one path, so the script no longer truncates it or touches a sibling directory that shares the first line.
