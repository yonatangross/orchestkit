Release PRs bump every plugin's version, not only the first

release-please changes a version in docs/site/lib/generated/plugins-data.ts only on lines tagged // x-release-please-version. The generator tagged the first plugin only. When ork-extras became a second plugin, the 10.13.0 release PR bumped ork, left ork-extras at 10.12.0, and the build then regenerated the file and failed on the difference. Pick a version to walk through the release.

What changed

scripts/generate-docs-data.js now tags the version line of every plugin through scripts/lib/release-version-marker.js, and plugins-data.ts is regenerated with both tags. tests/unit/test-plugins-data-release-marker.mjs fails on the old generator (2 FAIL) and passes on the new one (3 ok).

OrchestKit release tooling. Versions shown are the 10.12.0 to 10.13.0 release.
