OrchestKit / hook regression evidence

Arguments are flags.
Body text is not.

The GitHub label and milestone enforcers now read quoted shell words instead of searching raw command text. Equals syntax stays untouched. A shell example inside an issue body cannot impersonate a label.

Real built runner · PreToolUse JSON · No GitHub writes

01 / Equals-form label

gh issue create --title "Fix crash" --label=bug

Before

updatedInput.command
... --label=bug --label bug

A second label was appended.

After

{"continue":true,"suppressOutput":true}

Silent success. Original input preserved.

02 / A shell example in the body

gh issue create --title "Fix crash" --body "ls -l output"

Before

{"continue":true,"suppressOutput":true}

False positive: the body concealed the missing label.

After

updatedInput.command
gh issue create --title "Fix crash" --body "ls -l output" --label bug

The missing label is inferred as intended.

03 / Equals-form milestone

gh issue create --title "Fix crash" --milestone="v1"
gh issue create --title "Fix crash" --milestone=v1

Before / both commands

additionalContext
No --milestone set. Consider assigning to a milestone for sprint tracking.

Incorrect advisory despite an explicit milestone.

After / both commands

{"continue":true,"suppressOutput":true}

No milestone advisory.

04 / Existing spaced flags remain valid

gh issue create --title "Fix crash" --label bug
gh issue create --title "Fix crash" --milestone v1

Before / both commands

{"continue":true,"suppressOutput":true}

After / both commands

{"continue":true,"suppressOutput":true}

Method and boundaries

Captured from src/hooks/bin/run-hook.mjs pretool/bash/gh-label-enforcer and pretool/bash/gh-milestone-enforcer, using real PreToolUse JSON on stdin. Baseline bundles were built from unchanged main source at bf977faa; fixed bundles were built from this branch. Every invocation exited 0. Long rewrite payloads above show the changed command field.

Tests also cover attached shorthand, quoted values, escaped spaces, empty values, missing values, option terminators and malformed quoting. This is literal argv inspection, not shell expansion or GitHub API validation.
