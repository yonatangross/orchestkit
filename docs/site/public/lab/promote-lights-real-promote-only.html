Match only real promote PRs into main

In the live demo, /lights reported a promote for an ordinary PR into main. Matching now requires head dev (or PROMOTE_HEAD), or the promote label.

Simulate open PRs (base main)

Click a case to see what /lights tracks.

Contract

  • Ordinary PR into main: track nothing (store delete, no clock).
  • Head dev (default) or configured PROMOTE_HEAD: track that PR.
  • Any head with label promote: track that PR.
  • Plugin validate requires literal $.env.get("PROMOTE_HEAD"), not optional chaining on $.env.
