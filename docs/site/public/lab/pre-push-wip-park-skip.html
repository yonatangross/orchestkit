The version gate now skips wip/ park branches

Branch fix/pre-push-wip-park-skip, 2026-11-11. One pattern, scripts/ci/version-skip-pattern.sh, decides for both the pre-push hook and version-check.yml. A wip/ branch publishes a parked commit so nothing is lost; it never becomes a release, so a version bump there would be a ghost version (#1457). Before this change the gate refused wip/park-2026-11-11/fix-5172 outright.
