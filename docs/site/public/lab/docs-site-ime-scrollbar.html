Docs site: Enter in an IME, and standard scrollbars

Chrome's Modern Web Guidance scan found two real problems on the docs site. In the Prompt Enhancer demo, the Enter that confirms a Japanese, Chinese or Korean composition also sent the draft. And the site styled scrollbars with WebKit-only rules. Pick a key event to see what the demo does now.

Scope. One handler in the Prompt Enhancer lab page and one block in the docs site stylesheet. The nine dark-mode findings in generated lab pages are style only and are left alone.

The scrollbar change

The stylesheet now sets scrollbar-width: thin and scrollbar-color for every scroller. Browsers that support them use these; the ::-webkit-scrollbar rules stay as the fallback for older WebKit and Blink.
