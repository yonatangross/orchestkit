Word-based wrapper option parsing in the egress check

User-switch wrappers are recognized by walking their option words, not by measuring characters between the tool name and a flag. Inline command strings are compound only when a separator sits outside quoted spans.

How word walks and quoted separators work

  1. Tokenize the wrapper's simple-command words with shell quoting rules.
  2. Walk documented options by word; whitespace between words does not matter.
  3. An inline command body is scanned as its own segment when the option points at it.
  4. Separators inside quoted argument text stay argument data, not a compound split.
