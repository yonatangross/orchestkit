The stop condition that was the task

#4853 taught the task advisor to drop a stop condition as an obstacle ("stop if the deploy breaks"). It also dropped it when the next clause said to do it ("stop and check if a deploy to production is needed, then do it"), so the specialist ask vanished. A clause that refers back to the condition now keeps it, and a conditional "report only if" no longer turns the ask into a note.

How it decides

  • The stop span is still split at clause words, and its condition is still dropped when the routed match is the obstacle itself.
  • New: when the rest of the same sentence refers back to the condition (then, and or so plus do, run, apply, ship and the like plus it, that or this, or "if so"), nothing is dropped.
  • A follow-up that does not refer back ("then report it") or sits in the next sentence leaves a real obstacle dropped.
