Which plugin ships each skill after the ork-extras split

Core ork keeps 90 skills. 26 reference skills move to the opt-in ork-extras plugin and change their name from /ork:<skill> to /ork-extras:<skill>. Search any skill to see where it lives and how to call it.

ork (core, installed by default) ork-extras (opt-in)

The moved skills are the same files, published from the same repository; nothing was deleted. Until a release that contains ork-extras exists, its marketplace entry tracks main while stable ork stays pinned to its tag, so for one release the two can differ. Cursor installs ork-extras from the same OrchestKit marketplace as ork. Codex does not export it; Antigravity is not verified.
