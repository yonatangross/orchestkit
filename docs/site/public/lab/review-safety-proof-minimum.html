The safety_proof criterion gets a minimum, so the skill eval measures it

The review-pr rubric has a criterion, safety_proof, that asks a behavior-changing diff to state the one fact it is safe because of and the step of the proof ladder that fact reached. It has weight 0 and, until now, no min_blocker. The skill eval skips a dimension without a min_blocker, so the criterion was never measured. It now carries 4.0, the same as the other six. The review verdict does not change.

3 / What was checked

The contract test now asserts that every dimension, safety_proof included, carries the same min_blocker, and it has a control that fails on a rubric where safety_proof has none or a different one. On the base commit that test failed 2 of 8; with the floor it passes 8 of 8. No eval was run: the minimum takes effect at the next eval.
