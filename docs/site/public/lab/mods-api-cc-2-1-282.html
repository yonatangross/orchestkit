ORCHESTKIT LAB · MODS API CC 2.1.282

Three mods ported to the Claude Code 2.1.282 mods API

On 2.1.282 every hook in the three mods was skipped or threw, so none of them did anything. This PR ports each one to the current API. It also lists them in the marketplace, and it stops the build from overwriting their versions with the ork version.

Build fix in the same PR

scripts/stamp-counts.sh and bin/bump-version.sh treated every marketplace entry with source.ref == "main" as the ork tracking entry. The mods also track main, so every npm run build rewrote their versions (1.0.1 and 0.0.2) to the ork version. The writers now skip mods/ entries. With the fix a full stamp leaves the tree clean; with it reverted all three versions are overwritten.

How to try them

Mods load only with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1. Install from the orchestkit marketplace (claude plugin install secrets-veil@orchestkit, same for the other two), or load one for a single session with --plugin-dir mods/<name>. secrets-veil masks tool results, not the text you type.
