ORCHESTKIT LAB · MODS · CC 2.1.282

promote-lights draws its band and can watch any PR

Shows the CI checks of a pull request as a row of colored lights right above where you type, so you see red before you ask to merge.

Before

/lights answered no PR tracked (orchestkit has no promote PR), the band was a plain object that would not draw, and a new session first showed the lights a previous session stored.

After

The band is built from $.ui.resolve(e) elements. /lights watch owner/repo#N or PROMOTE_LIGHTS_WATCH tracks any open PR in any repo. session.start clears stale lights before the first tick.

Proof

Live 2.1.282 watching yonatangross/orchestkit#4428: 16 green, 4 yellow, 1 red, BLOCKED, drawn above the prompt and pinned in the status line. Tests 89 passed.

Mods load only with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1; Function Hooks is still an unannounced Claude Code prototype. PR fix/mods-promote-lights-visible.
