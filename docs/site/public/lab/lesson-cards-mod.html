Lesson Cards Mod

Interactive demo of the lesson-cards mod for OrchestKit. Shows hint cards when tool calls match known patterns.

Example Cards

lesson: cancelled-check-is-not-pass block
Cancelled CI tiers are not pass. Never trust a green rollup on a moved head.
Fix: Use `gh pr view` with --json to check mergeStateStatus, or rely on merge-on-required.sh
lesson: pg-dump-fc-gzip-redundant warn
pg_dump -Fc output is already compressed; piping to gzip is redundant
Fix: Remove the gzip pipe, use -Fc alone

Try It

Simulate a Bash command:
$ gh pr view && gh pr checks

Hook Footprint

  • hooks: session.start{}, tool.call{Bash/Edit/Write}, ui.render{ToolUse}, command.register{}
  • calls: $.fs.read, $.fs.list, $.fs.stat, $.ui.notice, $.ui.invalidate
  • negative: no process.run, no http.fetch, no I/O on hot path

How It Works

  1. At session.start, load lesson-patterns.json from newest hq-ext
  2. Also load newest three lessons.md files
  3. On tool.call, blank quoted strings/heredoc bodies, then match patterns
  4. On match, add context to tool result and card to ui.render
  5. Classic guard unchanged - cards are additive during pilot
