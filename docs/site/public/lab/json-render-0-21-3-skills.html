json-render 0.21.3: what changed for the skills

Four OrchestKit skills teach agents to use json-render: json-render-catalog, multi-surface-render, mcp-visual-output and ai-ui-generation. This change moves their tested version to 0.21.3. Every claim was checked against the published type definitions and compiled code of 0.19.0, 0.20.0 and 0.21.3, not against release notes. All 36 symbols the skills import still exist, and no package removed an export.
