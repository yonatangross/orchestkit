ORCHESTKIT LAB · MODS · PROMOTE-LIGHTS

The lights band shows problems, not a wall of green

Above your prompt you now see one line that says how the pull request is doing, and a separate line for each check that is not green. When everything passes, it is one line.

Approved design

🚦 #4435  3afff24  BLOCKED   19 🟢  0 🟡  2 🔴
   🔴 PR Playground
   🔴 CI Summary
❯ _

One summary line always; then one line per check that is not green, with its full name, red first, then cancelled, then yellow.

Before

Every required check was one entry in a single long row. With 21 checks the row wrapped into four lines, names were cut at 28 characters, and several checks read the same.

Live on Claude Code (all green: one line)

🚦 yonatangross/orchestkit#4436  0797957  CLEAN   21 🟢  0 🟡  0 🔴
────────────────────────────────────────────────────────────
❯ _
  ⚠ promote-lights: watch yonatangross/orchestkit#4436, 21 green

The per-check lines for red, yellow and cancelled are covered by unit tests; no open pull request had a failing required check at the time of the live run.

Mods load only with CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1. PR fix/promote-lights-compact-band.
