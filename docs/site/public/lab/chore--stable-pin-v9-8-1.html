Stable users move to v9.8.1

The ork entry in .claude-plugin/marketplace.json is the pinned stable channel. This change points it at the new patch tag. The ork-alpha channel, which tracks main, is not touched.

The pin

version 9.8.0
ref v9.8.0
→
version 9.8.1
ref v9.8.1

Both fields move in one write, made by scripts/bump-stable-pin.sh 9.8.1, so they cannot disagree.

What 9.8.1 fixes

Claude Code 2.1.283 warns at startup about if keys on hook matcher groups. Claude Code never read those keys, so removing them changes no hook behavior on any version. It only clears the warning. The fix is #4062 on main, backported to the 9.8 line in #4517 and tagged v9.8.1.

Why this PR is manual

On main, release.yml opens this pin PR by itself for every stable tag. The v9.8.1 tag was cut from release/9.8.x, whose older release.yml has no pin job, so nothing opened it.
