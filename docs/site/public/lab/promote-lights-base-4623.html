promote-lights: a configurable promote base

Branch fix/promote-lights-base-4623, refs #4623. A repo that promotes development into qa, then qa into main, always got no promote PR open.

Verdict. Both session-start PR queries passed --base main, and the session tracked base was the literal "main". PROMOTE_BASE (default main) now goes to both queries and becomes the tracked base, so the required checks come from that branch. Head globs such as release/* are not in this change.
