Why the dist sync died at ten seconds

The sync builds a tree in the dist repo through POST /git/trees. It split requests by bytes only, and a file the repo already has costs no bytes. So almost every entry went in one request, which timed out with a 502. Move the slider to see the requests a release makes. The timing here is illustrative, scaled from four measured failures at about 10.8 seconds for 1,879 entries.
