Tool ids stay readable

With secrets-veil on, a tool_use id such as toolu_01 followed by 22 letters and digits showed as dots. The id is long and random, so the high-entropy layer took it for a secret: in a test, 890 of 1000 ids of that shape crossed the bar. These ids are public request handles, not credentials. Version 0.0.8 lets a token that is exactly an Anthropic id through the entropy layer and keeps every other layer on it.

The exemption covers the entropy layer only and only a whole token of the exact id shape. A real secret pasted with one of these prefixes in front of it, at the id length, would pass that one layer.
