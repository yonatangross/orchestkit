A failed status clear keeps the lights

Each tick of promote-lights stores the CI lights, then clears the status line so the state is drawn only once, in the band. In 0.0.9 that clear ran inside the tick's try block. If Claude Code rejected it, the catch stored an error over the snapshot it had just saved, and the band showed the error instead of the lights. Now the clear is best effort, like the existing startup warning: a rejected clear leaves the lights in place.
