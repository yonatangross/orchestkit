Agent stdout is data, not Python source

Issue #4219 (audit AF-4): expect/scripts/report.sh built a Python program inside python3 -c "..." with bash double-quote expansion, so RUN_RESULT and RUN_SUMMARY parsed from the browser agent's stdout became Python source. A page that steers the agent's RUN_COMPLETED line got code execution on the operator's machine. The fix sends every run field to Python through environment variables inside a quoted-heredoc program.
