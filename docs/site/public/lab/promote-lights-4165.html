The contract

Hooks: session.start, turn.complete, command.register, ui.render with { component: 'AbovePrompt' }.

Calls: $.process.run (gh CLI), $.fs.read, $.session.repo, $.clock.every, $.store.get/set, $.ui.status, $.ui.invalidate.

Cancelled checks are never green. Missing is red. One REST page per minute, only while PR is open.
