MCP Registry / publish check

The registry description fits in 100 characters

The MCP Registry rejects a server.json description longer than 100 characters with 422 validation failed: body.description expected length <= 100. The publish job failed on the last three releases (10.17.0, 10.18.0 and 10.18.1) because the description was 153 characters.

The check is tests/manifests/test-server-json.sh (check 4). It counts characters the way jq length does, fails on a missing, empty or non-string description, and accepts 1 to 100. This page counts the same way, does not call the registry, and publishes nothing.
