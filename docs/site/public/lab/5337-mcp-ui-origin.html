Only the embedding frame may hand the card its commands.

The docs MCP install picker is an iframe. Before this fix, its message listener accepted render data from any window at any origin, and the copy button wrote a copy field the page never displayed. A hostile page could show a benign install command while poisoning the clipboard. The picker now checks e.source === window.parent and an origin allowlist matching the CSP frame-ancestors hosts, validates every host entry against a schema, and derives the clipboard text from the commands on display.

What changed

trusted(e) requires e.source === window.parent and an origin in the allowlist (chatgpt.com, claude.ai, orchestkit.dev, orchestkit.yonyon.ai and their subdomains, plus localhost for development). Host entries are rebuilt through a schema that keeps only the fields the view uses. The copy button now carries commands.join(" && ") computed from what is on screen, so the clipboard can never disagree with the display. Outbound replies aim at the established host origin instead of "*" once the handshake lands.
