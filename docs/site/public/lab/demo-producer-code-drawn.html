Code-drawn mode: the storyboard page renders the film

PR for demo-producer. One page draws every frame with drawFrame(g, t). The owner approves that page, and the same code, unchanged, renders the film. First used for the OrchestKit verify reel: 32 s, 1080x1920, 960 frames.

1. The contract: any frame from t alone

This box is a miniature storyboard page. Every frame is a pure function of t: no state between frames, no clock, no unseeded random. So frame 600 renders alone, in any order, in parallel, and the render matches the approved page.

A podium, a spark that climbs, six threads to six lanes. The real reel draws the skill, its workflow, agents, hooks and the grade the same way.

3. What compare.py would say: real numbers from the verify reel

Twelve moments of the approved page against the same moments decoded from the film (true pairs), and eleven controls that pair each still with the next moment's frame (must differ). Both images are blurred 2 px first. Move the limits and watch which side breaks.

4. Limits worth knowing

The compare samples moments. A defect between them, such as a scene sliding over a fixed footer during a pan, passes it. On the verify reel the first fresh review found five such defects in a film that matched 12 of 12 moments, so references/code-drawn-mode.md keeps a fresh reviewer reading strips across every transition.
