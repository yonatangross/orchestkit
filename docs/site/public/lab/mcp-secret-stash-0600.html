The truncation that ate the upload URL

#4510. mcp-output-transform cut every oversized mcp__* result to 1200 head + 600 tail and refused the reversible stash on any secret pattern. A presigned S3 URL always carries an ASIA STS credential, so the full result was unrecoverable. This page replays the transform in the browser: old behaviour on the left, this PR on the right.
