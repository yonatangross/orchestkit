When a source names policyHelper, the file fallback is blind

Doctor's preferred read is /status. The file and MDM fallback only works when the selected managed source's values are what the session uses. If that source sets policyHelper, the helper's emitted managedSettings object is the only managed settings for the session. Reading managed-settings.json then reports a value the session may not use.
