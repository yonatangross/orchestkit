Sync plugins/ork to the orchestkit-plugin dist repo

The Anthropic plugin directory validates a whole repo archive, capped at 50 MiB compressed. This repo is about 77 MiB. A new sync-dist job in release.yml publishes only plugins/ork, at the root of yonatangross/orchestkit-plugin, on every GA release.

Size against the cap

Before

  • The directory would read the orchestkit repo itself
  • About 77 MiB compressed, over the 50 MiB cap
  • The plugin sits under plugins/ork, not at the root

After

  • On a GA tag from main, scripts/ci/dist-sync.mjs builds the dist tree from the tagged plugins/ork
  • One commit created through the API, signed by GitHub, main fast-forwarded, same vX.Y.Z tag
  • About 3.8 MiB compressed, .claude-plugin/plugin.json at the root

Guards
