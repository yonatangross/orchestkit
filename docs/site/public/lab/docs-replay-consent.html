Session replay never starts without consent

Branch: fix/docs-replay-consent, a follow-up on #5098. Files: docs/site/instrumentation-client.ts, docs/site/lib/posthog-loader.ts, one test.

Before: after a visitor pressed Decline, the replay gate still existed, so entering a /docs/reference page could call startSessionRecording() on an opted-out client. After: the gate starts a recording only while PostHog is loaded and consent stands (isPostHogLoaded()), and withdrawing consent stops any recording in progress before capture is opted out.
