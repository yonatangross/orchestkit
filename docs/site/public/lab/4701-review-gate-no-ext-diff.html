REVIEW-PR POST GATE · #4701

A git read under review-pr runs no diff driver

A git config or .gitattributes written before /ork:review-pr ran can name a program git runs while it prints a diff: diff.external, a diff=<driver> command, or a textconv driver. git status runs core.fsmonitor. The gate now asks every diff-printing read for both --no-ext-diff and --no-textconv, and drops git status.

Declared limit: a program set in git config under a key the gate does not check, or in global or system config, is not covered. core.hooksPath is allowed: a test arms every hook name, and the only one an allowed read fires is post-index-change (a worktree git diff), so the gate refuses git reads while that hook exists. A %G log format is refused (it runs the signing program). A follow-up runs review-pr's git reads with a sanitized config.

The skill's own diff commands (SKILL.md range row, rule-check diffCommand, review-fanout reader prompt) pass both flags, so the gate never blocks the skill. This page simulates the flag rule only; the gate also checks every other flag and path.
