Evidence gate

Three distinct checks

  1. The field must belong directly to this event's schema object. A neighbouring object, a nested field, or a longer property name does not supply evidence.
  2. The schema-accepted and reviewed-exception sets must be disjoint.
  3. New binary prose produces an advisory stale-classification message. Prose is not runtime trace evidence.

The fixture covers these cases and removes the new exit condition to prove that an unsupported schema claim would otherwise pass.
