OrchestKit / Shadow evidence

Keep both picks with every decision.

This interactive example shows the canonical logging fields and the exact review bucket. All inputs are synthetic. A disagreement is a candidate for review, not a correctness label.



What is persisted
Every active expect invocation appends a row to .expect/jev-shadow.jsonl, even when the request or configuration fails. The same row remains in the stdout protocol and saved step report. New files use mode 0600.


Route runs before the main model chooses an executor. Synchronous PreToolUse pairs the requested Skill or Agent selection using the exact prompt ID; Stop records no executor for a direct response. The report collapses pending and paired revisions so each decision counts once. Category pairs the Haiku classification with Jev after both settle.


Export the review queue
node scripts/jev-shadow-report.mjs --confident-wrong /path/to/sessions .expect/jev-shadow.jsonl


The export includes rows where agree=false AND jev_confidence >= floor. Unlabeled decisions remain awaiting_adjudication. Transport errors and unobserved incumbents cannot enter this bucket.
