Press Enhance, Undo and Send from the keyboard

In the default terminal mode Claude Code does not ask the terminal for mouse clicks, so a click on the band selects text and never reaches a button. The band had no keys and no hint, so its buttons looked dead. Version 0.1.1 gives each action a key and says how to reach it.

Action0.1.00.1.1
Enhanceclick (fullscreen only), or ctrl+x tab, Tab, Enterctrl+x tab, then e
Undothe samectrl+x tab, then u
Sendthe samectrl+x tab, then s
How to find outnothing on screena dim line on the band names the keys

The keys work only while the band holds the focus, never while you type in the prompt, so typing e, u or s in a draft does nothing to the band. Esc gives the focus back to the prompt.
