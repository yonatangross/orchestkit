memory-lens: recall goes to Claude, not to your pane

memory-lens recalls the few memories related to each prompt and hands them to Claude as context. Before this change it also drew one line under every prompt listing what it recalled. On a busy session those lines add up. Now the line is written to the debug log only; Claude still gets the same context, and /memory-lens show <n> prints a recalled memory whenever you ask.
