orank: advertise the Actions MCP and document the safe path

orchestkit.yonyon.ai scored 97/100 (A+) on the 2026-10-03 scan. The product MCP shipped on 2026-09-14 but no index pointed at it, and no page told an agent how to try OrchestKit without touching real data. This PR is docs and indexes only; no MCP code changed.

Verdict. The OrchestKit Actions MCP (/api/mcp/actions, three read-only tools) existed with a server card, tests and one docs section, but orank sees a docs MCP and no product MCP because /llms.txt, the developer-resource index, the sitemap, the schema-map and the RFC 9727 API catalog never named it. All five now do. A new getting-started/sandbox page gives the sandbox path a predictable URL.
