Lesson Cards Mod: Independent Unit Test and Live Session Verification

In the initial demo, the installed hq-ext pretool lesson-guard intercepted block-severity commands first. This update adds an isolated unit test asserting both notice and UI card, and documents live session verification using commands permitted by the guard.

Unit Test Isolation

The unit test directly exercises hook registration: feeding a tool.call matching a known pattern asserts the notice via $.ui.notice and the card element rendered under ui.render, independent of other installed hooks.

✓ feeds matching tool.call and asserts card and lesson notice independently (10ms)

Live Session Observation

When hq-ext is active, block-severity commands are denied upfront. To observe cards live:

  • Floor bullets: Run an indexed command like vm_stat from floor lessons.md. The guard does not inspect bullets, so the card renders.
  • Warn patterns: Run a command matching a warn pattern like alembic stamp head. The guard permits execution with exit 0, allowing lesson-cards to render.
