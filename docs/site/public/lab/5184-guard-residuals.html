Six shapes that slipped the guard, closed.

The guard denies npm ci when it would run in a directory whose node_modules is a symlink, because that empties the tree the link points at. Of the nineteen exploit shapes the Vercel Security Review filed on #5184, thirteen already deny or ask on main. These six still let the install run silently, because the reader fabricated a state bash does not produce. Each is fixed at root: the reader now follows the shape the way bash does, or marks the parse uncertain and asks when a linked tree is reachable.

The six fixes

    
29b heredoc quotes. Under an unquoted delimiter every quote is data and backticks still expand. Bodies from unquoted delimiters are marked and read with quotes literal, so a backticked npm ci inside apostrophes is seen.

    
36 IFS alternates. Only IFS forms that always yield separators are blanked; ${IFS:+x} now expands to its operand, so a cd that bash reads as two operands fails as it should.

    
38 options after the end-of-options marker. cd flags are consumed as a leading run only; an option-looking word after the marker is positional, so cd -- -L /decoy is the two operands bash refuses.

    
37 cd -P. A realpath probe resolves the physical landing directory through symlinks, and the move is marked uncertain, so the stayed-behind and physical dirs are both probed.

    
40 quoted braces. Braces read inside quotes or escapes are literal: 'a{b,c}' stays one directory instead of expanding to a and losing the linked name.

    
41 the directory stack. pushd records where it left and popd returns there, through subshell save and restore; an empty stack or a rotation marks the parse uncertain.

    
Every shape that cannot be modeled marks the parse shaky: the guard then probes every directory word against every base the command passed, and asks rather than allow.
