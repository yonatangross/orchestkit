Loki discovery command, before and after

The Step 1 discovery command in otel-gateway-source.md used to build its curl flag from a variable. It now spells the flag plainly. Pick a version to see the text a reader copies and the argv curl actually receives.

Offline example only. Nothing here runs a command or contacts an endpoint.

Why the change
  • Both versions pass the same argv to curl, so behavior does not change.
  • The plain spelling is what curl's own docs and a reader expect, and it survives copy and paste without a shell variable.
  • A CLI flag inside a code fence is code, not prose. A dash rule that objects to it should allow code spans rather than bend the command.
