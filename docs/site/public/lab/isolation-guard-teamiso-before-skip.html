Isolation guard: teammate check runs before the Phase 4 skip

The isolation guard skips Phase 4 of agent-phases.md, because those agents write specs, not files. The skip ran before the teammate check, so a Phase 4 teammate that passes isolation on its call (which makes it a plain subagent) was not flagged. The teammate check now runs first; the skip covers only the writer checks.

What changed

  • tests/agents/test-agent-isolation-allowlist.sh: the scan is a function, so the test can run it on a fixture. A pinned self-check feeds it a Phase 4 teammate with isolation and fails when that call is not flagged.
  • Order: the name plus isolation check runs before the Phase 4 skip. The skip still covers the writer checks, so the writer count stays at 32.
  • Why: CodeRabbit thread 4239736563 on #4695, answered there as a follow-up. No current template was exposed; this closes the gap for future ones.
