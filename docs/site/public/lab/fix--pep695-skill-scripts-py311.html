One line of Python 3.12 in a 3.11 codebase

Release blocker on beta.58. #4265 ruff-linted the 51 skill scripts under target-version = "py313". The UP rules read PEP 695 generics as the modern form and rewrote safe_llm_call.py:210 into async def call_llm[T: BaseModel]. Every pyproject declares requires-python >=3.11, so the script could no longer even compile on a supported interpreter.

The two spellings


  

    
gatepython3.11 compileallruff UP (py311 pin)

    
result

  

  
The fix is two-sided: per-file-target-version
  pins src/skills/** to py311 so the UP046/UP047 family can never
  suggest the rewrite again, and CI byte-compiles src/skills with
  a real python3.11 whenever the runner ships one.
