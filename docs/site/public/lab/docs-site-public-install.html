OrchestKit / Contributor setup

Public docs installs, without a token

One shared installer for local contributors, CI, and Vercel. Registry access still installs the real analytics package. An authentication failure can use the local no-op stub, but never in Vercel production.

npm run setup --prefix docs/site

Shared installer

    Leave the checkout as it was

    The installer backs up package.json and package-lock.json before installing. Its exit trap restores both originals, even if the fallback fails. A successful stub install stays in node_modules, not in the tracked dependency specifications.

    The lockfile is reconciled in place for the stub, never discarded. Other install errors remain fatal.
