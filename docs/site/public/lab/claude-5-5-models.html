Branch chore/claude-5-5-models-2026-11-03 (#5020). Every Claude model id orchestkit ships as a default now names a 5.5 model: claude-opus-5-5, claude-sonnet-5-5 and claude-haiku-5-5. Four skill scripts change in src/skills/ and are mirrored to plugins/ork/skills/ by the build, plus one coordination schema default and two workflow defaults. 2. Who skips sampling params

Claude 5-series models answer a non-default temperature, top_p or top_k with a 400. Two scripts drop those keys by model prefix. Haiku 4.5 still took them; Haiku 5.5 does not, so claude-haiku-5 joins the list in both llm-fallback-chain.py and ollama-provider-template.py. Pick a model id to see what each script sends.

Without this line. Before the change, a GENERAL task in ollama-provider-template.py moved to claude-haiku-5-5 would not match any prefix, get temperature=0.0, and fail with a 400 on its first call.
