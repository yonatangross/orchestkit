Changelog fragment recovery

A stray percent sign in a changelog link used to replace the entire release feed with an error. These links exercise the real changelog on this site.

Malformed fragment

Before, #% showed an error page. Now the changelog treats it as a missing anchor and keeps the default feed.

Encoded release
