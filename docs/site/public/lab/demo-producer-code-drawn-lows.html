1. Name check: try a folder

Every still in the approved folder must be named by its time in seconds. Anything else is now refused by name before a single image is measured, instead of crashing the sort.

2. Still holds trip the control, on purpose

The control pairs each approved still with the next moment's frame and must see a difference. If the storyboard holds still between two sampled moments, the two frames match and the run fails as BLIND. Move the slider: when the next moment shows nothing new, the control cannot tell them apart. (Simplified to the mean limit alone; compare.py also needs under 1 % of pixels off to call two frames a match.)
