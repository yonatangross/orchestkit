The auto label now survives the default timeout.

gh-label-enforcer appends --label to a simple gh issue create. Later in the same chain, default-timeout-setter adds timeout: 120000 when none is set. The dispatcher gave every hook the original input and kept only the last updatedInput, so the timeout rewrite replaced the labelled command while the label context still told the model it was added.

The change

In src/hooks/src/pretool/bash/sync-bash-dispatcher.ts, each hook's updatedInput is applied on top of the current tool input, and the next hook receives that result. Fields no hook touches (for example run_in_background) are kept instead of being dropped by the timeout rewrite.
