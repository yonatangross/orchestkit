Masking stays fast on long lines

Some long single-line outputs (minified code, repeated tokens) made the masker rescan the same text over and over, which could hold a session for several seconds. The scan now moves past each match instead of restarting inside it, overlapping matches from different detectors are merged so every part of a secret stays covered, the end marker of a key block is searched once, the masked text is built in one pass, and a single value over a fixed size is withheld rather than scanned.
