What the old host does

Pages: /, /docs/*, /about, /llms.txtone 301 to the same path on orchestkit.devLinks and search results land on the new host in one hop.
/api/*, /mcp, /mcp.json, /askserved, 200MCP clients POST here, and many clients do not follow a 301 on POST.

The production Vercel alias orchestkit.vercel.app now sends its 301 straight to orchestkit.dev, so it never chains through the old host.

Caveats

  • An anonymous identity assertion minted before the switch (issuer and audience both the old host) keeps verifying until its own expiry, at most 30 days, with the same key and checks. A mixed pair is still rejected, and nothing mints the old issuer any more (operator decision, 2026-10-20).
  • The after score is unknown until this deploys. It is read from the orank scan API, not estimated here.
  • The older card at /.well-known/mcp/server-card.json stays served, with its tools list, for checkers that already read it.
