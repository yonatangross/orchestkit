# SubagentStart Hooks

**3 hooks** registered for the `SubagentStart` lifecycle event.

| Hook | Matcher | Behavior | Description |
|------|---------|----------|-------------|
| <span id="hook--subagent-start-agent-view-titler"></span>`agent-view-titler` | `*` | Injects | Derives a short, human-readable title for each subagent at spawn and emits it on `hookSpecificOutput.sessionTitle` so the agent-view row is readable. |
| <span id="hook--subagent-start-unified-dispatcher"></span>`unified-dispatcher` | `*` | Injects | Consolidates 3 SubagentStart hooks into a single process spawn. |
| <span id="hook--lifecycle-webhook-forwarder"></span>`webhook-forwarder` | `*` | Fire-and-forget | Registered for every CC event type in hooks.json (async: true). Delegates to telemetry.emit() which fans out to pluggable sinks (JSONL local + HTTP remote). No-op when no sinks are active. |
