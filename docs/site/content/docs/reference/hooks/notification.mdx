# Notification Hooks

**3 hooks** registered for the `Notification` lifecycle event.

| Hook | Matcher | Behavior | Description |
|------|---------|----------|-------------|
| <span id="hook--notification-desktop"></span>`desktop` | `*` | Fire-and-forget | Sends rich desktop notifications with context (repo, branch, task). |
| <span id="hook--notification-sound"></span>`sound` | `*` | Fire-and-forget | PRIMARY PATH (#1847): returns the top-level `terminalSequence` hook-output field with a BEL (\u0007). CC emits it to the user's terminal, which rings the terminal bell, zero process spawns, works on macOS + Linux, command hooks only. |
| <span id="hook--lifecycle-webhook-forwarder"></span>`webhook-forwarder` | `*` | Fire-and-forget | Registered for every CC event type in hooks.json (async: true). Delegates to telemetry.emit() which fans out to pluggable sinks (JSONL local + HTTP remote). No-op when no sinks are active. |
