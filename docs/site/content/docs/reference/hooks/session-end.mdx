# SessionEnd Hooks

**7 hooks** registered for the `SessionEnd` lifecycle event.

| Hook | Matcher | Behavior | Description |
|------|---------|----------|-------------|
| <span id="hook--lifecycle-sync-session-end-dispatcher"></span>`sync-session-end-dispatcher` | `*` | Blocks | Consolidates 2 synchronous SessionEnd hooks into a single dispatcher. |
| <span id="hook--lifecycle-session-handoff-generator"></span>`session-handoff-generator` | `*` | Silent | Session Handoff Generator, Writes a structured handoff YAML at session end |
| <span id="hook--lifecycle-usage-summary-reporter"></span>`usage-summary-reporter` | `*` | Fire-and-forget | Posts OrchestKit-specific session data to HQ API that CC's native HTTP hooks can't provide: hooks_triggered, event_counts, decisions, problems, solutions. |
| <span id="hook--lifecycle-webhook-forwarder"></span>`webhook-forwarder` | `*` | Fire-and-forget | Registered for every CC event type in hooks.json (async: true). Delegates to telemetry.emit() which fans out to pluggable sinks (JSONL local + HTTP remote). No-op when no sinks are active. |
| <span id="hook--telemetry-sync-mjs"></span>`telemetry-sync.mjs` | `*` | Fire-and-forget | - |
| <span id="hook--lifecycle-goal-budget-guard"></span>`goal-budget-guard` | `*` | Fire-and-forget | Goal Budget Guard: SessionEnd Hook (M140 G5 #1791, #4684) |
| <span id="hook--lifecycle-session-finalizer"></span>`session-finalizer` | `*` | Fire-and-forget | Marks this session's row as status='completed' and stamps ended_at. This hook deliberately does NOT delete the session row so post-mortem queries still work. (An older comment here described CASCADE on settings_overrides + locks; those tables were dropped in 005, #3353.) |
