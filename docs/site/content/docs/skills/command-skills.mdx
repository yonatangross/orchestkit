## What Are Command Skills?

Command skills are the **43 skills** with `user-invocable: true` in their frontmatter. You trigger them by typing `/ork:<name>` in Claude Code. Each one is a structured workflow that guides Claude through a multi-step process, often spawning parallel agents and pulling in reference skills automatically.

Command skills differ from reference skills in three ways:

1. **You invoke them explicitly** with the `/ork:` prefix.
2. **They define workflows**, not just knowledge: step-by-step processes with decision points.
3. **They compose other skills** via the `skills:` frontmatter field, pulling in reference skills as needed.

## How Command Skills Compose Reference Skills

Every command skill lists the skills it needs in its frontmatter `skills:` field. When you invoke it, those skills load into context. For example, `/ork:implement` pulls in:

```yaml
skills:
  - api-design
  - react-server-components-framework
  - testing-unit
  - testing-e2e
  - testing-integration
  - explore
  - verify
  - memory
  - scope-appropriate-architecture
  - chain-patterns
```

You do not need to remember which reference skills exist. The command skill knows what knowledge it needs and loads it.
