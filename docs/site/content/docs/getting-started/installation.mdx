Pick the host you actually use. Claude Code is the full plugin (<Count k="skills" /> skills, <Count k="agents" /> agents, <Count k="hooks" /> hooks). Cursor gets the same `ork` plugin minus Claude hook scripts. Codex gets the portable `ork-codex` pack. Muse Code (Meta) loads skills from `.agents/skills`. Pi installs via the shipped `pi` manifest. OpenCode and other Agent Skills clients start with 12 skills on skills.sh.

Click a chip. That copies the install. Cursor is a marketplace slug, not a fake CLI.

## After you install

Then run `/ork:setup`. That is the in-bot wizard (scan, skills, MCP, project knobs). The browser picker below copies a host install command. It is not `/ork:setup --configure`.

Project settings (protected branches, commit scope, localhost browser, log level, optional webhook) are documented in [Configuration](/docs/getting-started/configuration#project-settings-wizard).
