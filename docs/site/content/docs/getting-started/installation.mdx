## Choose your host

Pick the host you actually use. Claude Code is the full plugin (<Count k="skills" /> skills, <Count k="agents" /> agents, <Count k="hooks" /> hooks). Cursor gets the same `ork` plugin minus Claude hook scripts. Codex gets the portable `ork-codex` pack. Devin installs the `ork` plugin from git (skills load, hooks do not yet). OpenCode and other Agent Skills clients start with 12 skills on skills.sh. Muse Code (Meta) loads skills from `.agents/skills`. Pi installs via the shipped `pi` manifest. Antigravity reads workspace `.agents/skills`.

Click a card to copy its install command. Cursor is a marketplace slug, not a fake CLI.

See the [host matrix](/docs/getting-started/hosts) if you are unsure which row you are on. Measured engine notes (pi, Codex, Cursor) live in [OrchestKit on pi, Codex and Cursor](/docs/guides/orchestkit-on-pi-codex-cursor).

Coming from Superpowers (official Anthropic marketplace)? Complementary. [OrchestKit vs Superpowers](/docs/getting-started/superpowers).

## After you install

Then run `/ork:setup`. That is the in-bot wizard (scan, skills, MCP, project knobs). The browser picker below copies a host install command. It is not `/ork:setup --configure`.

Project settings (protected branches, commit scope, localhost browser, log level, optional webhook) are documented in [Configuration](/docs/getting-started/configuration#project-settings-wizard).
